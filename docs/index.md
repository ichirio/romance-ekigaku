# ロマンスの疫学 ― 科学的思考への誘い

> 恋の病は、いつ、誰に、どれだけ起きているのか。

---

恋ヶ丘電鉄という私鉄がある。全8駅。起点は**恋ヶ丘**、終点は**成就**。

この沿線では昔から、恋が流行り病のように広がると言われてきた。
思い立ったその日に告白してしまう街もあれば、五年でも言い出せない街もある。
駅前にはたいてい占い館があり、恋に悩む人はそこへ行く。

その沿線に、**路須万縁（ろすま ゆかり）**という疫学者がいる。
恋ヶ丘大学の教授で、学生からは**ロマンス先生**と呼ばれている。
恋の話になると早口になるが、数字の話になるともっと早口になる。
学生が数字を持ってくると、必ず最初にこう言う。

> 「**その分母、なんですか？**」

このサイトは、その研究室の記録である。

測るのは恋の病。使うのは疫学の道具 ―
リスク、発生率、有病割合、リスク比、発生率比、リスク差、そして NNT。
題材は柔らかいが、**道具のほうは一切手加減していない**。

## 恋の病という見立て

日本語には昔から「恋煩い」「恋の病」という言い方がある。
これが都合のいいことに、疫学の語彙をそっくりそのまま受け止める。

| 疫学の言葉 | 恋ヶ丘沿線では |
|---|---|
| 感受性者（susceptible） | 恋に落ちうる人 |
| 曝露（exposure） | 占い館に通う、学園祭に行く |
| 潜伏期（incubation period） | 出会ってから自覚するまでの時間 |
| 罹患・発生（incidence） | 恋に落ちる |
| 有病（prevalence） | いま恋煩いの最中である |
| 罹病期間（duration） | 片思いが続いた長さ |
| 治癒（recovery） | 成就する、あるいは諦める |
| 再感染（reinfection） | また別の人に恋をする |
| 流行（epidemic） | 学園祭シーズンの恋の多発 |

一語も改造せずに乗る。だから、恋を数えることは、そのまま疫学の練習になる。

## 三駅めの話

沿線の三駅めに、**片思ヶ丘**という駅がある。
調べてみると、駅利用者の 16.7 % が片思いの最中だった。起点の恋ヶ丘は 9.1 %。

学生の**占部みくじ**は、これを見て言った。
「片思ヶ丘のほうが、恋が生まれやすい街なんですね」

ロマンス先生は、しばらく黙ってからこう答えた。

> 「片思ヶ丘の恋の発生率は、**恋ヶ丘の半分**です」

同じ二つの街の数字が、見る指標を変えるだけで逆を向く。
片思ヶ丘は恋が生まれる街ではなく、**恋が終わらない街**だった。

この取り違えを数式ごと分解するのが [4-5](ch04/ch04-05.md) で、
そこへ至るまでの道具立てを組むのが、第4章の残りの回である。
