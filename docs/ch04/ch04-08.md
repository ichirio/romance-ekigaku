# 4-8　効果の測り方② ― 差と「益」

> 恋ヶ丘大学　― リスク差、寄与危険割合、NNT、乗法と加法

---

合コンの幹事を一手に引き受けている四年生が、研究室にやってきた。

> 「先生。合コンが 2.18倍というのは聞きました。それで、あの ―
> **何人呼べば、一組ぶん恋が増えるんでしょう**」

雪野が即答した。

> 「2.18倍なので、2人に1人くらいでは？」

> 「**比からは、その答えは出ません**」とロマンス先生。
> 「会長がお聞きなのは、**差**の話です」

---

## リスク差（RD）

前回と同じ表を使います。

| | 人数 | 恋に落ちた | リスク |
|---|---|---|---|
| 合コンに出た | 80 | 32 | 40.0 % |
| 出なかった | 120 | 22 | 18.3 % |

$$
RD = R_1 - R_0 = 0.400 - 0.183 = 0.217
$$

**21.7 パーセントポイント**です。

!!! warning "「％」ではなく「ポイント」"
    40.0 % と 18.3 % の差は「21.7 **ポイント**」であって「21.7 %」ではありません。
    「21.7 % 増えた」と書くと、
    18.3 % が 22.3 % になった（1.217倍）という別の意味になります。

### 比と差の性質の対比

| | リスク比 \(RR\) | リスク差 \(RD\) |
|---|---|---|
| 基準値 | **1** | **0** |
| 範囲 | 0 〜 ∞ | −1 〜 1 |
| 尺度 | **乗法**（何倍か） | **加法**（何ポイント動くか） |
| 得意なこと | 原因としての**強さ**を表す | **影響の大きさ**を表す |
| 単位 | なし | なし（ただし人数に翻訳できる） |

---

## NNT ― 効果を人数に翻訳する

リスク差の逆数をとると、こうなります。

$$
NNT = \frac{1}{RD} = \frac{1}{0.217} = 4.6
$$

> 「およそ 5人を呼べば、1年のうちに一組ぶん恋が増える計算になります。
> ―― もし 2.18倍が、本当に合コンの効果ならば、ですが」

これが **NNT（number needed to treat、治療必要数）** です。
幹事はこれを「呼ぶべき人数」と呼びたがりますが、
報告書に書く名前は **治療必要数（NNT）** です。

!!! tip "NNT が偉いところ"
    「2.18倍」は専門家の言葉ですが、
    「**5人に1人**」は誰にでも伝わります。
    NNT は、統計量を**行動の単位**に翻訳する道具です。

---

## 同じ「2.18倍」でも、益はまるで違う

ここが、この回でいちばん大事なところです。

合コンについて、もう一つ「**1年以内に結婚した**」というアウトカムでも調べたとします。
こちらのリスクは、出た群 2.0 %、出なかった群 0.92 % でした。

| アウトカム | \(R_1\) | \(R_0\) | \(RR\) | \(RD\) | \(NNT\) |
|---|---|---|---|---|---|
| 恋に落ちる | 40.0 % | 18.3 % | **2.18** | 21.7 pt | **約 5人** |
| 結婚する | 2.0 % | 0.92 % | **2.18** | 1.08 pt | **約 93人** |

!!! danger "リスク比は、まったく同じ 2.18"
    それでも、一組ぶん増やすのに必要な人数は **5人と 93人**。**19倍近い違い**です。

    **比は「どれだけ強い原因か」を表し、差は「どれだけ大きな影響か」を表します。**
    もとの発生がまれなら、比が大きくても、実際に動く人数はごくわずかです。

雪野が唸る。

> 「じゃあ、どっちが正しいんですか」

> 「**どちらも正しい。問いが違うだけです**」とロマンス先生。

| 知りたいこと | 使う指標 |
|---|---|
| これは恋を生む原因として強いのか（原因の探究） | **比**（RR・IRR） |
| この大学で何人呼べば何組増えるのか（意思決定） | **差**（RD・NNT） |
| 集団全体の恋のうち、どれだけが合コンのおかげか | **寄与割合**（次節） |

---

## 寄与危険割合 ― どれだけが合コンの「おかげ」か

### 曝露群のうち、どれだけが合コンによるものか

$$
AF_e = \frac{R_1 - R_0}{R_1} = \frac{RR - 1}{RR} = \frac{2.18 - 1}{2.18} = 0.542
$$

合コンに出た人に起きた恋のうち、**54.2 % は合コンに帰せられる**という意味です。
残りの 45.8 % は、出なくても起きていた恋ということになります。

前回、小堀が「出ても出会えるとは限らない」と言いました。
その「限らない」ぶんが、この 45.8 % です。

### 集団全体では

集団全体のリスクは \(54/200 = 27.0\) % でした。

$$
PAF = \frac{R_{\text{全体}} - R_0}{R_{\text{全体}}} = \frac{0.270 - 0.183}{0.270} = 0.321
$$

この200人に1年で生まれた恋のうち、**32.1 % は合コンに帰せられる**。
\(AF_e\)（54.2 %）より小さくなるのは、
200人の全員が合コンに出ているわけではないからです。
集団寄与割合は、**効果の強さと曝露の広まり方の両方**で決まります。

!!! quote "ロマンス先生"
    「弱い原因でも、集団じゅうに広まっていれば、全体への寄与は大きくなります。
    逆に、猛烈に強い原因でも、10人しか曝露していなければ全体は動きません。
    **公衆衛生が比だけを見ないのは、このためです。**」

## 有意 差子助教、登場する

ここで、有意差子助教が資料を持って現れた。

> 「先生、この 2.18倍、**p = 0.003 で有意でした**。効果ありと結論できますね」

ロマンス先生はペンを置いた。

> 「差子さん。あなたが今、私に**教えてくれたこと**は何ですか」

> 「……有意だということです」

> 「**それは、いくつなんですか。**
> 私が知りたいのは 2.18 という値と、その値がどのくらい頼りないかです。
> **p 値は、そのどちらも教えてくれません。**
> 『効果がある/ない』の二択に潰すために、
> せっかく測った 2.18 を捨てるのは、もったいないと思いませんか」

差子助教は口をひらきかけて、やめた。

**「有意か否か」ではなく、「どのくらいか、どのくらいの幅で」。**
第5章では、この 2.18 に区間を付けます。

## 手を動かす

=== "Python"

    ```python
    import math

    R1, R0 = 32 / 80, 22 / 120

    RD  = R1 - R0
    RR  = R1 / R0
    NNT = 1 / RD

    print("RD  :", round(RD, 4), "→", round(RD * 100, 1), "ポイント")  # 0.2167 → 21.7
    print("NNT :", round(NNT, 2), "→ 約", math.ceil(NNT), "人")        # 4.62 → 約 5 人
    print("AFe :", round((RR - 1) / RR * 100, 1), "%")                 # 54.2 %

    R_total = 54 / 200
    print("PAF :", round((R_total - R0) / R_total * 100, 1), "%")      # 32.1 %

    # 同じ RR でも、まれなアウトカムでは NNT がまるで違う
    r1m = 0.020
    r0m = r1m / RR
    print("結婚 RR :", round(r1m / r0m, 2))                            # 2.18
    print("結婚 NNT:", round(1 / (r1m - r0m), 1), "→ 約",
          math.ceil(1 / (r1m - r0m)), "人")                            # 92.3 → 約 93 人
    ```

=== "R"

    ```r
    R1 <- 32 / 80; R0 <- 22 / 120

    RD  <- R1 - R0
    RR  <- R1 / R0
    NNT <- 1 / RD

    cat("RD  :", round(RD, 4), "→", round(RD * 100, 1), "ポイント\n") # 0.2167 → 21.7
    cat("NNT :", round(NNT, 2), "→ 約", ceiling(NNT), "人\n")         # 4.62 → 約 5 人
    cat("AFe :", round((RR - 1) / RR * 100, 1), "%\n")                # 54.2 %

    R_total <- 54 / 200
    cat("PAF :", round((R_total - R0) / R_total * 100, 1), "%\n")     # 32.1 %

    r1m <- 0.020
    r0m <- r1m / RR
    cat("結婚 RR :", round(r1m / r0m, 2), "\n")                       # 2.18
    cat("結婚 NNT:", round(1 / (r1m - r0m), 1), "→ 約",
        ceiling(1 / (r1m - r0m)), "人\n")                             # 92.3 → 約 93 人
    ```

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　ポイントと％を混ぜる"
    40.0 % と 18.3 % の差は **21.7 ポイント**。
    「21.7 % 増えた」と書くと 1.217倍の意味になり、まったく別の主張になります。

!!! failure "誤り2　比だけを報告する"
    「2.18倍」だけでは、5人に1人の話なのか 93人に1人の話なのか分かりません。
    **比と差は、いつも一緒に報告する。**

!!! failure "誤り3　NNT に期間を付けない"
    NNT は必ずリスク差から作られ、リスクには期間が要ります。
    正しくは「**1年間に**一組増やすために 5人」。
    期間のない NNT は、期間のないリスクと同じで未完成です。

## この回に出てきた用語

| 用語 | English | この回での意味 |
|---|---|---|
| リスク差 | risk difference (RD) | リスクの引き算 |
| 治療必要数 | number needed to treat (NNT) | 一組増やすのに必要な人数 |
| 曝露群寄与危険割合 | attributable fraction in the exposed | 合コンに出た人の恋のうち合コンのおかげの割合 |
| 集団寄与危険割合 | population attributable fraction | 集団全体の恋のうち合コンのおかげの割合 |
| 乗法尺度 | multiplicative scale | 何倍か |
| 加法尺度 | additive scale | 何ポイント動くか |

## 練習問題

**問1**　ある要因の \(RR\) は 5.0、\(R_0\) は 0.0002（1万人に2人）だった。
1万人がこの要因に曝露したとき、増える件数はおよそ何件か。

??? success "解答"
    \(R_1 = 5.0 \times 0.0002 = 0.0010\)。
    \(RD = 0.0010 - 0.0002 = 0.0008\)。

    1万人 × 0.0008 = **8件**。

    \(RR = 5.0\) は非常に強い関連ですが、
    もとがまれなので、増えるのは1万人あたり8件です。
    \(NNT = 1/0.0008 = 1250\) 人。

    **比の大きさと、影響の大きさは別物です。**

---

**問2**　「合コンのリスク差は 21.7 ポイントです」と報告した。
この報告に足りないものを二つ挙げよ。

??? success "解答"
    1. **期間**。リスク差はリスクの引き算なので、
       「1年間の」が必要です。
    2. **不確かさの幅**。21.7 ポイントは推定値であって、
       200人という標本から得られた一つの数字にすぎません。
       区間推定を添えるべきです（第5章）。

    なお三つ目を挙げるなら、**交絡への言及**です。
    この 21.7 ポイントが合コンの効果と言えるかどうかは、
    第6章の検討を経なければ分かりません。

---

**問3**　幹事が言った。
「うちは 2.18倍と聞いたので、隣の大学の 1.5倍より効果が大きいと理解しました」
この理解に問題があるとすれば、どこか。

??? success "解答例"
    **比だけを比べているところ。**

    2.18倍と 1.5倍のどちらが「大きな影響」かは、
    それぞれの集団の**もとのリスク（\(R_0\)）**によって逆転しえます。

    | | \(RR\) | \(R_0\) | \(RD\) | \(NNT\) |
    |---|---|---|---|---|
    | 合コン | 2.18 | 0.5 % | 0.59 pt | 約 170人 |
    | 隣の大学 | 1.50 | 30 % | 15.0 pt | 約 7人 |

    （\(R_0\) をこう仮定した場合）比が小さい隣の大学のほうが、
    実際に動く人数ははるかに多くなります。

    **「効果が大きい」と言うときは、比の話なのか差の話なのかを先に決めること。**
