    4-5　片思いの有病割合 ― 一番危ない勘違い¶

    恋都大学と片恋野高校　― 有病割合、\(P/(1-P) = IR \times D\)、有病を発生と読む罠

    雪野が調査票の束を抱えて研究室に走り込んできた。 夏のあいだ、高大連携先の片恋野高校に通って集めてきたものである。

    「先生！ 大発見です。 片恋野高校は、住民の 16.7 % が片思い中なんです。 うちの学生はたったの 9.1 %。 片恋野のほうが、恋が生まれやすいんですよ！」

    ロマンス先生は、しばらく黙ってから言った。

    「雪野さん。片恋野高校の恋の発生率は、うちの学生の半分です」

    有病割合の定義¶

    有病割合（prevalence）は、ある一時点で、その状態にある人の割合です。

    \[ P = \frac{\text{その時点で片思い中の人数}}{\text{その時点の全人数}} \]
    発生（incidence） 有病（prevalence）
    数えるもの 出来事（恋に落ちた） 状態（片思い中である）
    時間の扱い 期間にわたって数える 一瞬を切り取る
    たとえ 毎年の入学者数 いまの在学者数

    「発生は流れ、有病は溜まりです」とロマンス先生。 「この大学に、いま何人の学生がいるか。それは 毎年何人入ってくるかと、一人がどれだけ長く居座るかの両方で決まります。 在学生が多いからといって、入試が活発だとは限らない。 全員が留年しているだけかもしれないでしょう」

    溜まりの式¶

    定常状態（人の出入りが釣り合っている状態）では、次が成り立ちます。

    \[ \frac{P}{1-P} = IR \times D \]
    • \(P\) … 有病割合
    • \(IR\) … 発生率
    • \(D\) … 平均罹病期間（ここでは片思いが続く平均の長さ）

    左辺 \(P/(1-P)\) は有病オッズです。

    どこから来る式か（読み飛ばし可）

    全人数を \(N\) とします。定常状態では、 単位時間に新しく発症する人数と、単位時間に治る人数が釣り合っています。

    • 新しく発症する人数 ＝ \(IR \times\)（感受性者の数）＝ \(IR \times N(1-P)\)
    • 治る人数 ＝ （有病者の数）÷（平均罹病期間）＝ \(N P / D\)

    この二つを等号で結ぶと

    \[ IR \times N(1-P) = \frac{NP}{D} \quad\Longrightarrow\quad IR \times D = \frac{P}{1-P} \]

    「入ってくる勢い × 留まる長さ ＝ 溜まり具合」。それだけの式です。

    有病割合が小さいときの近似

    \(P\) が小さければ \(1-P \approx 1\) なので、\(P \approx IR \times D\)。 有病割合 ≒ 発生率 × 罹病期間。 これが直感的な形です。

    二つの集団を分解する¶

    雪野が見た 16.7 % と 9.1 % を、式で分解します。

    集団 発生率 \(IR\) 平均罹病期間 \(D\) 有病オッズ 有病割合 \(P\)
    恋都大学の学生（すぐ告白する） 0.20 /人年 0.5年 0.10 9.1 %
    片恋野高校の生徒（言い出せない） 0.10 /人年 2.0年 0.20 16.7 %

    結論が、ひっくり返ります

    • 有病割合比 \(PR = 16.7 / 9.1 = 1.83\) … 片恋野高校のほうが 1.8倍多い
    • 発生率比 \(IRR = 0.10 / 0.20 = 0.50\) … 片恋野高校のほうが 半分しか生まれていない

    同じ二つの集団について、比が逆方向を向いています。

    片恋野高校は「恋が生まれやすい」のではありません。恋が終わらないのです。 新しい恋は大学生の半分しか生まれていないのに、 一度始まった片思いが4倍長く続くので、いつ写真を撮っても片思い中の生徒が多く写る。

    二つの数字には、どちらにも理由があります。

    発生率が低いのは、出会いが少ないから。 片恋野高校はクラスが三年間ほぼ変わりません。新しく出会う相手そのものが少ない。 合コンにも出ません。

    罹病期間が長いのは、言い出せないから。 大学生は思い立った週に告白して、成就するか振られるかで決着をつけます。 高校生はそれを何年も抱えます。

    この二つが逆向きに効いた結果が、16.7 % という一つの数字です。 有病割合を見ているかぎり、どちらが効いているのかは分かりません。

    ロマンス先生が黒板を指した。

    「雪野さん、あなたが見たのは流れではなく、渋滞です」

    もう一つの例：交際という状態¶

    同じ式は、恋の病のもう一つの病期にも使えます。恋都大学で恋愛期（交際中）を測ってみます。

    集団 \(IR\)（交際開始） \(D\)（交際の平均継続） \(P\)（交際中の割合）
    恋都大学 0.15 /人年 4.0年 37.5 %

    発生率は片恋野高校（0.10）よりわずかに高いだけです。 それでも有病割合は 37.5 % と大きくなる。\(D\) が効いているからです。

    では、有病割合は使えない指標なのか¶

    そんなことはありません。目的が違うだけです。

    知りたいこと 使う指標 理由
    原因を探したい（何が恋を生むか） 発生率・リスク 罹病期間の影響が混じらない
    予防の効果を測りたい 発生率・リスク 同上
    いま何人がケアを必要としているか 有病割合 現時点の負担そのものを表す
    相談室の席数を決めたい 有病割合 「いま悩んでいる人」の数が要る

    ひとことで言えば、原因を知りたいなら発生、負担を知りたいなら有病。

    片恋野高校に恋愛相談室を作るなら、有病割合 16.7 % が正しい設計根拠です。 「片恋野高校には恋を生む何かがある」と言いたいなら、有病割合は使えません。

    手を動かす¶

    import pandas as pd

groups = pd.DataFrame({
    "group": ["大学(片思い)", "片恋野(片思い)", "大学(交際)"],
    "IR": [0.20, 0.10, 0.15],   # /人年
    "D":  [0.50, 2.00, 4.00],   # 年
})

groups["odds"] = groups["IR"] * groups["D"]
groups["P"]    = groups["odds"] / (1 + groups["odds"])

print(groups.assign(P_pct=lambda d: (d["P"] * 100).round(1)))
#           group    IR    D  odds         P  P_pct
# 0    大学(片思い)  0.20  0.5   0.1  0.090909    9.1
# 1  片恋野(片思い)  0.10  2.0   0.2  0.166667   16.7
# 2      大学(交際)  0.15  4.0   0.6  0.375000   37.5

p_kata, p_koi = 0.166667, 0.090909
print("有病割合比 PR :", round(p_kata / p_koi, 2))   # 1.83
print("発生率比  IRR :", round(0.10 / 0.20, 2))      # 0.5

    ロマンス先生の赤ペン ― よくある誤り¶

    誤り1　有病割合を発生の証拠として使う

    「片思い中の人が多い ＝ 恋が生まれやすい」は成り立ちません。 有病割合には罹病期間が掛かっているからです。 原因を語りたいなら、発生率かリスクを持ってくること。

    誤り2　有病割合の差を「効果」と呼ぶ

    ある要因が有病割合を上げていたとして、それは 発生を増やしたのか、期間を延ばしたのか、区別がつきません。 「言い出せない性格」は恋を生みませんが、片思いを長引かせます。 有病割合しか見ていないと、この二つが同じ顔をします。

    誤り3　有病割合を「率」と呼ぶ

    日本語では「有病率」と書く習慣がありますが、 実体は割合（0〜1、無単位、時点の写真）であって、率ではありません。

    この回に出てきた用語¶

    用語 English この回での意味
    有病割合（時点有病割合） (point) prevalence いま片思い中の人の割合
    平均罹病期間 \(D\) mean duration 片思いが続く平均の長さ
    有病 prevalent cases いま片思いの最中にいる人
    発生 incident cases 新しく恋に落ちた人
    有病割合比 prevalence ratio (PR) 有病割合どうしの比
    定常状態の関係式 steady-state relation 溜まりの式

    練習問題¶

    問1　A大学とB大学で、片思いの有病割合はどちらも 20 % だった。 A大学の発生率は 0.25 /人年、B大学は 0.05 /人年である。 それぞれの平均罹病期間 \(D\) を求めよ。

    解答

    \(P/(1-P) = 0.20/0.80 = 0.25\)。よって \(D = 0.25 / IR\)。

    • A大学：\(D = 0.25 / 0.25 = \) 1.0年
    • B大学：\(D = 0.25 / 0.05 = \) 5.0年

    有病割合が同じでも、中身はまったく違います。 A大学は「よく生まれ、早く決着する」、B大学は「めったに生まれないが、5年引きずる」。 有病割合だけを見ていると、この違いは永遠に見えません。

    問2　片恋野高校に恋愛相談室を開いたところ、 片思いの平均罹病期間が 2.0年から 1.0年に短縮した。発生率は 0.10 /人年のまま変わらない。 有病割合はどう変わるか。

    解答
    • 前：オッズ \(= 0.10 \times 2.0 = 0.20\) → \(P = 0.20/1.20 = \) 16.7 %
    • 後：オッズ \(= 0.10 \times 1.0 = 0.10\) → \(P = 0.10/1.10 = \) 9.1 %

    有病割合はほぼ半減します。 恋は一件も減っていないのに、です。

    ここが重要な含意です。もし片恋野高校の有病割合だけを見て 「相談室のおかげで恋が減った」と評価したら、まったくの誤りになります。 相談室がしたのは、発生を減らすことではなく、決着を早めることでした。

    問3　次の主張のうち、有病割合を根拠にしてよいのはどれか。

    1. 片恋野高校には、恋を生みやすい何かがある
    2. 片恋野高校に恋愛相談員を何人配置すべきか決めたい
    3. 合コンは恋の発生を増やす
    4. 片恋野高校の生徒は、恋の悩みを抱えている時間が長い
    解答

    2 と 4。

    2 は「いま何人が悩んでいるか」という負担の話なので、有病割合が正しい根拠です。 4 は「罹病期間が長い」という主張で、まさに有病割合を押し上げている要因そのものです。

    1 と 3 は発生の主張なので、有病割合では支持できません。 発生率かリスクを測る必要があります。
