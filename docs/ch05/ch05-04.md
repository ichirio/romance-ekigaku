# 5-4　症例対照研究② ― 対照をどこから選ぶか

> 密度サンプリング、ケースコホート抽出、累積サンプリング

---

暦野定時が、三枚の紙を並べた。

> 「先生。症例は同じ 54人、起源集団も同じ 200人です。
> **対照 54人の選び方だけ**を三通りやってみました」

| | オッズ比 |
|---|---|
| 選び方 A | **2.50** |
| 選び方 B | **2.18** |
| 選び方 C | **2.97** |

みくじが顔をしかめた。

> 「値がばらばらじゃないですか。どれが正しいんですか」

> 「**三つとも正しい**」とロマンス先生。
> 「推定しているものが、それぞれ違うだけです」

---

## 同じ起源集団を、三つの角度から見る

起源集団は第4章と同じ 200人です。おさらいしておきます。

| | 人数 | 恋に落ちた | 観察人年 | 落ちなかった |
|---|---|---|---|---|
| 占った | 80 | 32 | 64.0 | 48 |
| 占わなかった | 120 | 22 | 110.0 | 98 |
| 合計 | 200 | 54 | 174.0 | 146 |

この集団について、真の値はすでに分かっています。

$$
RR = 2.18 \qquad IRR = 2.50 \qquad OR_{\text{コホート}} = 2.97
$$

症例 54人は三通りとも共通です。**変えるのは対照 54人の抜き方だけ**。

---

## A. 密度サンプリング

**各症例が発生したその時点で、まだリスク集団に残っている人から一人選ぶ。**

恋に落ちた瞬間ごとに、その瞬間の「まだ落ちていない人の集まり」から
くじを引くイメージです。この集まりを**リスク集合（risk set）**というので、
**リスク集合サンプリング**とも呼びます。

長く追跡された人ほど、くじに参加する回数が増えます。
つまり**選ばれる確率が人時に比例する**。

対照 54人の期待される内訳は、人年 64.0 : 110.0 の比になります。

| | 症例 | 対照 |
|---|---|---|
| 占った | 32 | **19.9** |
| 占わなかった | 22 | **34.1** |

$$
OR = \frac{32 \times 34.1}{22 \times 19.9} = 2.50
$$

**発生率比と一致します。** 偶然ではありません。
対照が人時に比例して選ばれているので、
オッズ比の分母がそのまま人時の比になるからです。

!!! success "密度サンプリングの含意"
    **希少疾病近似は要りません。**
    アウトカムが 27 % 起きていようが 50 % 起きていようが、
    オッズ比は発生率比を推定します。

### 対照が、あとで症例になってもよい

ここが直感に反するところです。

ある学生が 5月に対照として選ばれ、9月に恋に落ちて症例にもなったとします。
**それでかまいません。**

> 「5月の時点では、その人はまだリスク集団の一員でした」とロマンス先生。
> 「対照は**その時点のリスク集団を写し取るための標本**です。
> あとでどうなったかは、その時点の写真とは関係がありません」

みくじが食い下がる。

> 「でも、同じ人が症例にも対照にも出てくるんですよ」

> 「出てきます。そして、**除いてはいけません。**
> 除くと、長く残った人ほど対照から抜け落ちて、人時の比が壊れます」

---

## B. ケースコホート抽出

**追跡開始時のコホート全体から、無作為に選ぶ。**

まだ誰も恋に落ちていない時点の 200人から、くじで 54人を引きます。
すでに恋に落ちるはずの人も、そうでない人も、同じ確率で引かれます。

対照の期待される内訳は、80 : 120 の比になります。

| | 症例 | 対照 |
|---|---|---|
| 占った | 32 | **21.6** |
| 占わなかった | 22 | **32.4** |

$$
OR = \frac{32 \times 32.4}{22 \times 21.6} = 2.18
$$

**リスク比と一致します。**
対照が開始時のコホートを代表しているので、
オッズ比の分母が 80 : 120、つまりリスクの分母の比になります。

こちらも**希少疾病近似は要りません。**
そして、同じ対照群を別のアウトカムにも使い回せるという利点があります。

---

## C. 累積サンプリング

**追跡が終わった時点で、恋に落ちなかった人から選ぶ。**

いちばん素朴で、いちばんよく行われている方法です。
「1年後にまだ恋に落ちていない 146人」から 54人を引きます。

対照の期待される内訳は、48 : 98 の比です。

| | 症例 | 対照 |
|---|---|---|
| 占った | 32 | **17.8** |
| 占わなかった | 22 | **36.2** |

$$
OR = \frac{32 \times 36.2}{22 \times 17.8} = 2.97
$$

こんどはリスク比 2.18 とも発生率比 2.50 とも一致しません。
一致するのは、**コホート研究から計算したオッズ比 2.97** です。

!!! danger "希少疾病近似が要るのは、この方法だけ"
    累積サンプリングで得たオッズ比がリスク比に近づくのは、
    **アウトカムがまれなとき**だけです。

    ここでは全体の 27 % が恋に落ちています。まったくまれではありません。
    だから 2.97 と 2.18 が、これだけ離れます。

    「症例対照研究にはいつも希少疾病近似が必要」という説明を聞いたことがあるなら、
    それは**この方法だけの話**を、設計全体の話として一般化したものです。

---

## 三つを並べる

| 対照の抜き方 | どこから抜くか | 期待される対照 | オッズ比 | 推定しているもの | 希少疾病近似 |
|---|---|---|---|---|---|
| 密度サンプリング | 各症例発生時のリスク集合 | 19.9 / 34.1 | **2.50** | 発生率比 \(IRR\) | **不要** |
| ケースコホート抽出 | 追跡開始時のコホート | 21.6 / 32.4 | **2.18** | リスク比 \(RR\) | **不要** |
| 累積サンプリング | 追跡終了時の非症例 | 17.8 / 36.2 | **2.97** | オッズ比 | **必要** |

> 「だから」とロマンス先生。
> 「論文で『オッズ比 2.5』と読んだとき、最初に探すべきなのは信頼区間ではありません。
> **対照をどこから抜いたか**です。それが書いていなければ、
> その 2.5 が何の比なのか、こちらには決めようがありません」

!!! note "期待値と、実際の標本"
    表の 19.9 や 21.6 は**期待される内訳**です。
    実際に 54人を引けば整数になり、値はこの周りでばらつきます。

    ここで言えるのは「オッズ比がこの値を**推定している**」ということであって、
    一回の標本が必ずこの値を返すということではありません。
    そのばらつきの扱いは、精度の章の仕事です。

---

## 手を動かす

=== "Python"

    ```python
    cases_e, cases_u = 32, 22          # 症例（三通りとも共通）
    n_controls = 54

    schemes = {
        # 名前: (曝露あり側の重み, 曝露なし側の重み)
        "密度サンプリング":     (64.0, 110.0),   # 人年に比例
        "ケースコホート抽出":   (80, 120),       # 開始時コホートに比例
        "累積サンプリング":     (48, 98),        # 終了時の非症例に比例
    }

    for name, (w_e, w_u) in schemes.items():
        c_e = n_controls * w_e / (w_e + w_u)
        c_u = n_controls * w_u / (w_e + w_u)
        odds_ratio = (cases_e * c_u) / (cases_u * c_e)
        print(f"{name:<20} 対照 {c_e:5.1f} / {c_u:5.1f}   OR = {odds_ratio:.4f}")

    # 密度サンプリング       対照  19.9 /  34.1   OR = 2.5000
    # ケースコホート抽出     対照  21.6 /  32.4   OR = 2.1818
    # 累積サンプリング       対照  17.8 /  36.2   OR = 2.9697

    # 起源集団から直接計算した真の値
    print("IRR :", round((32 / 64.0) / (22 / 110.0), 4))    # 2.5
    print("RR  :", round((32 / 80) / (22 / 120), 4))        # 2.1818
    print("OR  :", round((32 / 48) / (22 / 98), 4))         # 2.9697
    ```

=== "R"

    ```r
    cases_e <- 32; cases_u <- 22
    n_controls <- 54

    schemes <- list(
      "密度サンプリング"   = c(64.0, 110.0),
      "ケースコホート抽出" = c(80, 120),
      "累積サンプリング"   = c(48, 98)
    )

    for (name in names(schemes)) {
      w <- schemes[[name]]
      c_e <- n_controls * w[1] / sum(w)
      c_u <- n_controls * w[2] / sum(w)
      or  <- (cases_e * c_u) / (cases_u * c_e)
      cat(sprintf("%-20s 対照 %5.1f / %5.1f   OR = %.4f\n", name, c_e, c_u, or))
    }

    # 密度サンプリング     対照  19.9 /  34.1   OR = 2.5000
    # ケースコホート抽出   対照  21.6 /  32.4   OR = 2.1818
    # 累積サンプリング     対照  17.8 /  36.2   OR = 2.9697

    cat("IRR :", round((32 / 64.0) / (22 / 110.0), 4), "\n")   # 2.5
    cat("RR  :", round((32 / 80) / (22 / 120), 4), "\n")       # 2.1818
    cat("OR  :", round((32 / 48) / (22 / 98), 4), "\n")        # 2.9697
    ```

三つのオッズ比は、それぞれ **\(IRR\)、\(RR\)、コホートのオッズ比**に厳密に一致します。
近似ではありません。

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　抽出法を書かずにオッズ比だけ報告する"
    同じデータから 2.18 も 2.50 も 2.97 も出ます。
    **どこから対照を抜いたかを書かなければ、その数字は解釈できません。**

!!! failure "誤り2　症例対照研究にはいつも希少疾病近似が必要だと思っている"
    必要なのは**累積サンプリングのときだけ**です。
    密度サンプリングは発生率比を、
    ケースコホート抽出はリスク比を、近似なしに推定します。

!!! failure "誤り3　あとで症例になった人を対照から除く"
    密度サンプリングでは**除いてはいけません**。
    対照はその時点のリスク集合の標本であり、
    除くと長く残った人ほど抜け落ちて、人時の比が壊れます。
    その結果、オッズ比は発生率比からずれます。

## この回に出てきた用語

| 用語 | English | 意味 |
|---|---|---|
| 密度サンプリング | incidence density sampling | 各症例の発生時点のリスク集合から対照を抜く |
| リスク集合サンプリング | risk-set sampling | 密度サンプリングの別名 |
| リスク集合 | risk set | ある時点でまだ発生していない人の集まり |
| ケースコホート抽出 | case-cohort sampling | 追跡開始時のコホートから対照を抜く |
| 累積サンプリング | cumulative sampling | 追跡終了時の非症例から対照を抜く |
| 希少疾病近似 | rare disease assumption | まれなとき OR ≒ RR。累積サンプリングでのみ必要 |
| オッズ比 | odds ratio (OR) | 何を推定するかは抽出法で決まる |

## 練習問題

**問1**　ある症例対照研究が、追跡終了時点で発症していない人から対照を選んだ。
アウトカムは対象集団の 40 % に起きていた。
得られたオッズ比 3.0 をリスク比として報告してよいか。

??? success "解答"
    **よくない。**

    累積サンプリングなので、希少疾病近似が必要です。
    ところがアウトカムは 40 % に起きており、まったくまれではありません。

    このとき**オッズ比はリスク比を大きく上回ります**。
    3.0 をリスク比として読むと、効果を過大に見積もることになります。

    報告するなら「オッズ比 3.0（累積サンプリング）」と、
    抽出法を添えて書きます。
    リスク比が欲しいなら、ケースコホート抽出に設計を変えます。

---

**問2**　密度サンプリングを行ったところ、
対照として選ばれた学生のうち 3人が、その後恋に落ちて症例にもなった。
解析からこの 3人を対照として除くべきか。

??? success "解答"
    **除いてはいけない。**

    対照は「選ばれた時点でリスク集合にいた」ことだけを条件とします。
    その後どうなったかは、その時点の曝露分布とは無関係です。

    むしろ除くと歪みます。長く追跡された人ほど後で症例になる機会が多いので、
    除去は**長く残った人を対照から系統的に取り除く**ことになり、
    人時に比例した抽出が壊れます。

    同じ人が症例としても対照としても登場するのは、
    密度サンプリングでは**正常な状態**です。

---

**問3**　起源集団 200人、症例 54人。
対照を「追跡開始時の 200人から無作為に 54人」選んだ。
このとき、対照の中に**すでに恋に落ちた人**が含まれることがある。問題か。

??? success "解答"
    **問題ではない。ケースコホート抽出では、それが仕様。**

    ケースコホート抽出の対照は「開始時のコホートを代表する標本」であり、
    その後発症するかどうかで選別しません。
    だからこそ、対照の曝露分布が**リスクの分母である 80 : 120** を反映し、
    オッズ比がリスク比 2.18 を推定します。

    もし発症者を除いてしまうと、それは累積サンプリング（C）に変わり、
    推定されるものがリスク比からオッズ比 2.97 へ移ります。
    **除くか除かないかで、答えの意味が変わる**ということです。
