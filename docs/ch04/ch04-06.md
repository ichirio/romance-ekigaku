# 4-6　途中で降りる人たち

> 恋ヶ丘大学　― 打ち切り、競合リスク、繰り返す事象

---

小堀定時が、別の台帳を広げた。二年生 100人を1年追った記録である。

> 「先生。この台帳、**どう数えても収まりが悪い**んです。
> 恋に落ちたのは 18人。ただ、**25人が推し活に目覚めて恋愛市場から降り**、
> **7人は連絡が取れなくなり**ました。
> 最後まで見られたのは、半分だけです」

雪野がすかさず言う。

> 「じゃあリスクは 18 / 100 で **18 %** ですね」

> 「その 100 人は」とロマンス先生。「**1年間、全員が恋に落ちうる状態でしたか？**」

---

## 追跡が終わる三つの終わり方

追跡の終わりには、意味の違う三種類があります。**混ぜてはいけません。**

| 終わり方 | 恋ヶ丘での例 | 疫学用語 | 分子に入るか |
|---|---|---|---|
| **アウトカムが起きた** | 恋に落ちた | 事象・発生 | **入る** |
| **観察が途切れた** | 転勤、連絡不通、研究終了 | **打ち切り**（censoring） | 入らない |
| **もう起こりえなくなった** | 推し活に目覚めて恋愛市場を降りた | **競合リスク**（competing risk） | 入らない |

!!! danger "打ち切りと競合リスクは、似ていて別物"
    - **打ち切り**：その人にその後何が起きたかは**分からないだけ**。
      恋に落ちたかもしれないし、落ちなかったかもしれない。
    - **競合リスク**：その人にはもう **絶対に起きない**。観察を続けても永久に起きない。

    死亡が典型的な競合リスクです。がんの発生を追っていて対象者が交通事故で死んだら、
    その人にがんはもう発生しません。**「分からない」のではなく「起きない」**のです。

雪野が食い下がる。

> 「でも、推し活を始めた人だって、また恋するかもしれないじゃないですか」

> 「**その通りです**」とロマンス先生。
> 「だから恋ヶ丘スタディでは、推し活離脱を**打ち切りに近いもの**として扱います。
> 何を競合リスクと呼ぶかは、**研究者が定義して宣言する**ことです。
> 天から降ってくる区別ではありません」

---

## 「18 %」の何が問題か

素朴なリスク 18/100 は、分母の100人が**全員1年間ずっと観察された**と仮定しています。
実際はこうでした。

| 人数 | 何が起きたか | 平均観察年数 |
|---|---|---|
| 18 | 恋に落ちた（そこで観察終了） | 0.5 |
| 25 | 推し活に目覚めて降りた | 0.5 |
| 7 | 追跡不能 | 0.5 |
| 50 | 1年間、何も起きず | 1.0 |

人時を足すと、

$$
PT = 18 \times 0.5 + 25 \times 0.5 + 7 \times 0.5 + 50 \times 1.0 = 75.0 \ \text{人年}
$$

100人年ではなく **75.0 人年**。**4分の1が消えています。**

$$
IR = \frac{18}{75.0} = 0.24 \ /\text{人年}
$$

率が一定と仮定して1年リスクに戻すと（→ [4-4](ch04-04.md)）、

$$
R = 1 - e^{-0.24} = 0.213
$$

| 数え方 | 1年リスク |
|---|---|
| 素朴（18/100） | 18.0 % |
| 人時から復元 | **21.3 %** |

!!! warning "打ち切りを無視すると、リスクは低く出る"
    途中で降りた人を「1年間恋に落ちなかった人」として分母に丸ごと数えると、
    **観察していない時間を「何も起きなかった時間」に化けさせてしまいます。**
    分母が水増しされ、リスクは過小評価されます。ここでは 3.3 ポイントぶんです。

---

## 打ち切りに許される前提

人時で扱えば万事解決、ではありません。静かな仮定が一つ入っています。

!!! abstract "無情報打ち切り（non-informative censoring）"
    **降りた人は、残った人と同じくらい恋に落ちやすかった** ―
    この仮定が成り立つときだけ、人時の計算は正当です。

これが崩れる例を考えてみます。

> **もし「恋が実らなかった人ほど推し活に走る」なら？**

その場合、降りた25人は残った人より恋に落ちにくかった集団です。
彼らを分母から外すと、残ったのは恋に落ちやすい人ばかり。
**率は高めに出ます。**

ロマンス先生が付け加える。

> 「**打ち切りが結果と関係しているとき、数字は静かに歪みます。**
> しかもこの歪みは、データを眺めても見えません。
> **見えないものは、仮定として書いておくしかない。**
> 第7章（選択バイアス）で正面から扱います」

---

## 何度も繰り返す人たち

恋の病がやっかいなのは、同じ人が1年に何度も罹ることです。

```
恋に落ちる ─▶ 恋煩い ─▶ 失恋 ─▶ 恋に落ちる ─▶ 恋煩い ─▶ 失恋 ─▶ …
  (発生1)              (再び感受性者)  (発生2)
```

!!! tip "繰り返す事象では、リスクではなく率を使う"
    リスクは「期間内に**1回以上**起きたか」という 0/1 の問いなので、
    **2回目以降を数えられません。**
    「年に平均1.2回失恋する」を表せるのは**率**だけです。

    人時の計算では、恋煩い中の期間は分母から外し、
    失恋して感受性者に戻ったら、また時計を動かします。

| 指標 | 繰り返す事象を扱えるか |
|---|---|
| リスク | **扱えない**（0〜1に収まってしまう） |
| 発生率 | **扱える**（1を超えてよい） |

これが、[4-3](ch04-03.md) で「率は 1 を超えてよい」と強調した理由です。

## 手を動かす

=== "Python"

    ```python
    import math
    import pandas as pd

    nisei = pd.DataFrame({
        "group":  ["恋に落ちた", "推し活で離脱", "追跡不能", "1年完走"],
        "n":      [18, 25, 7, 50],
        "years":  [0.5, 0.5, 0.5, 1.0],
        "event":  [1, 0, 0, 0],
    })

    pt    = (nisei["n"] * nisei["years"]).sum()
    cases = (nisei["n"] * nisei["event"]).sum()
    ir    = cases / pt

    print("人時 (人年)      :", pt)                       # 75.0
    print("発生 (件)        :", cases)                    # 18
    print("発生率 /人年     :", round(ir, 4))             # 0.24
    print("率から復元1年risk:", round(1 - math.exp(-ir), 4))  # 0.2134
    print("素朴なリスク     :", 18 / 100)                 # 0.18
    ```

=== "R"

    ```r
    nisei <- data.frame(
      group = c("恋に落ちた", "推し活で離脱", "追跡不能", "1年完走"),
      n     = c(18, 25, 7, 50),
      years = c(0.5, 0.5, 0.5, 1.0),
      event = c(1, 0, 0, 0)
    )

    pt    <- sum(nisei$n * nisei$years)
    cases <- sum(nisei$n * nisei$event)
    ir    <- cases / pt

    cat("人時 (人年)       :", pt, "\n")                    # 75
    cat("発生 (件)         :", cases, "\n")                 # 18
    cat("発生率 /人年      :", round(ir, 4), "\n")          # 0.24
    cat("率から復元1年risk :", round(1 - exp(-ir), 4), "\n") # 0.2134
    cat("素朴なリスク      :", 18 / 100, "\n")              # 0.18
    ```

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　打ち切られた人を「起きなかった人」として分母に残す"
    半年で降りた人は「1年間恋に落ちなかった人」ではありません。
    **半年しか見ていない人**です。
    観察していない時間を、静かな成功として数えないこと。

!!! failure "誤り2　打ち切りと競合リスクを同じ扱いにする"
    「分からない」と「もう起きない」は別です。
    競合リスクが多いのにリスクをそのまま計算すると、
    「もう起きない人」を「まだ起きうる人」として分母に置き続けることになります。

!!! failure "誤り3　繰り返す事象をリスクで報告する"
    「年に1.2回失恋する」は、リスクでは表せません。
    リスクの上限は 1 です。**繰り返す事象は率で**。

## この回に出てきた用語

| 用語 | English | この回での意味 |
|---|---|---|
| 打ち切り | censoring | 転勤・連絡不通で追跡が終わる |
| 競合リスク | competing risk | 推し活に目覚めて恋愛市場を降りる |
| 無情報打ち切り | non-informative censoring | 降りた人も残った人と同じだった、という前提 |
| 再び感受性者になる | return to risk set | 失恋して再び恋に落ちうる状態に戻る |
| 繰り返す事象 | recurrent events | 年に何度も失恋する |

## 練習問題

**問1**　次の追跡終了のうち、**競合リスク**として扱うのが最も自然なのはどれか。

1. 研究期間が終了した
2. 対象者が留学で1年間大学を離れた
3. 対象者が亡くなった
4. 対象者が調査票を返送しなくなった

??? success "解答"
    **3。**

    亡くなった人には、その後もう恋の病は発生しません。
    「分からない」のではなく「起きない」ので、競合リスクです。

    1・2・4 はいずれも**打ち切り**です。
    その後どうなったかが**分からなくなった**だけで、
    起こりうること自体は変わっていません。

---

**問2**　この100人で、もし「恋が実らなかった人ほど推し活に走る」が本当だったとする。
人時から計算した発生率 0.24 /人年 は、真の値より高く出るか、低く出るか。

??? success "解答"
    **高く出る（過大評価）。**

    降りた25人は、残った人より恋に落ちにくい集団だったことになります。
    その人たちが早く分母から抜けると、
    分母には**恋に落ちやすい人ばかり**が残ります。

    分子は変わらず分母が「濃い」人たちで占められるので、率は高めに出ます。
    これが**情報のある打ち切り**（informative censoring）で、
    人時の計算では直せません。第7章の主題です。

---

**問3**　恋ヶ丘大学の学生は、平均して年に 1.2回失恋する。
これを「1年リスク 120 %」と書いてよいか。理由も述べよ。

??? success "解答"
    **書いてはいけない。**

    リスクは「期間内に1回以上起きたか」を測る 0〜1 の量なので、
    **100 % を超えられません。**
    1.2 という数字は、繰り返しを含めた**率**（1.2 件/人年）です。

    正しくは「**失恋の発生率は 1.2 件/人年**」。
    率が 1 を超えているのは異常ではなく、
    **同じ人が年に複数回経験しうる事象だから**です。
