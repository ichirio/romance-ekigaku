# ロマンスの疫学 ― 科学的思考への誘い

> 恋の病は、いつ、誰に、どれだけ起きているのか。

---

恋ヶ丘大学は、毎年四月に二百人の新入生を迎える。
同じ日に、同じ場所に、同じ顔ぶれが揃う。
疫学者にとって、これほど数えやすい集団はない。

その大学に、**路須万兼寿（ろすまん かねす）**という疫学者がいる。
学生たちはこの名前を並べ替えて、いつのまにか**ロマンス先生**と呼ぶようになった。
恋の話になると早口になるが、数字の話になるともっと早口になる。
学生が数字を持ってくると、必ず最初にこう言う。

> 「**その分母、なんですか？**」

先生が数えているのは、**恋の病**である。

リスク、発生率、有病割合、リスク比、発生率比、リスク差、NNT ―
恋を数えるのに、疫学の道具はそのまま使える。

---

## 二駅先の街の話

大学から二駅のところに、**片思ヶ丘**という街がある。
調べてみると、住民の 16.7 % が片思いの最中だった。大学のある恋ヶ丘は 9.1 %。

学生の**雪野順**は、これを見て言った。
「片思ヶ丘のほうが、恋が生まれやすい街なんですね」

ロマンス先生は、しばらく黙ってからこう答えた。

> 「片思ヶ丘の恋の発生率は、**恋ヶ丘の半分**です」

同じ二つの街の数字が、見る指標を変えるだけで逆を向く。
片思ヶ丘は恋が生まれる街ではなく、**恋が終わらない街**だった。

この取り違えを数式ごと分解するのが [4-5](ch04/ch04-05.md) で、
そこへ至るまでの道具立てを組むのが、第4章の残りの回である。
