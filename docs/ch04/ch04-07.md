# 4-7　効果の測り方① ― 比

> 恋ヶ丘大学　― リスク比、発生率比、有病割合比、そしてオッズ比

---

四月、恋ヶ丘大学の掲示板は新歓の貼り紙で埋まる。
そのうちの何割かは、名目上サークルの説明会で、実質は合コンである。

雪野は半年かけて、恋ヶ丘スタディの参加者のうち、
**追跡開始の時点で恋に落ちうる状態にあった 200人**を、
「1年のあいだに合コンに出たか」で二つに分けた。
新入生だけの集団ではない。学年もばらばらの 200人である。

> 「先生、ついにデータが揃いました。**合コンは効きます**」

> 「まだ何も計算していませんね」とロマンス先生。「表を見せてください」

---

## 二つの集団を並べる

疫学の比較は、この形から始まります。

| | 人数 | 1年で恋に落ちた | 観察人時 |
|---|---|---|---|
| **合コンに出た**（曝露あり） | 80 | 32 | 64.0 人年 |
| **出なかった**（曝露なし） | 120 | 22 | 110.0 人年 |
| 合計 | 200 | 54 | 174.0 人年 |

ここまでは、ただの記述です。**比較は、指標を作ってから始まります。**

---

## リスク比（RR）

まず各群のリスク（1年）を出します。

$$
R_1 = \frac{32}{80} = 0.400
\qquad
R_0 = \frac{22}{120} = 0.183
$$

その比が**リスク比**です。

$$
RR = \frac{R_1}{R_0} = \frac{0.400}{0.183} = 2.18
$$

**合コンに出た人は、出なかった人に比べて、1年で恋に落ちるリスクが 2.18倍。**
「合コン」「1年」「恋に落ちる」の三点を添えないと、この数字はひとり歩きします。

### 「出れば出会える」わけではない

小堀が、表から目を上げずに言った。

> 「先生。**合コンに出たからって、出会えるとは限りませんよね。**
> 出ても何も起きなかった人のほうが、たぶん多い。
> それでも合コンは『原因』なんですか」

> 「原因です。ただし、**全員にとっての原因ではありません**」とロマンス先生。

先生は黒板に、円をいくつか描いた。

> 「一つの恋が生まれるには、いくつもの条件が同時に揃う必要があります。
> 恋に落ちうる状態であること。相手がいること。間が悪くないこと。
> ―― そのうちのどれか一つでも欠ければ、恋は生まれない。
>
> 合コンは、**その条件のひとつを埋める働き**をします。
> 埋まった人にとっては原因になり、埋まらなかった人にとっては何も起こさない。
>
> **だからリスクが 100 % にならないんです。**
> もし出れば必ず出会えるなら、曝露群のリスクは 40 % ではなく 100 % のはずでしょう」

雪野が口を挟んだ。

> 「じゃあ、40 % のうちどこまでが合コンのぶんなんですか」

> 「**いい質問です。**次回、その割合を数字で出します」

### 比の性質

| 性質 | 内容 |
|---|---|
| **基準値は 1** | 1 なら差がない。0 なら差がない、ではない |
| **範囲は 0 〜 ∞** | 上には無限、下には 0 まで |
| **非対称に見える** | 2倍と 0.5倍は「同じ強さ」だが、1 からの距離は違う |
| **対数で対称になる** | \(\log 2 = 0.693\)、\(\log 0.5 = -0.693\) |

!!! tip "だから比は対数で扱う"
    信頼区間を計算するときに \(\log RR\) を使うのは、この対称性のためです。
    第5章で効いてきます。

---

## 発生率比（IRR）

人時を使えば、率どうしでも比べられます。

$$
IR_1 = \frac{32}{64.0} = 0.500 \ /\text{人年}
\qquad
IR_0 = \frac{22}{110.0} = 0.200 \ /\text{人年}
$$

$$
IRR = \frac{0.500}{0.200} = 2.50
$$

RR は 2.18、IRR は 2.50。**同じデータなのに、値が違います。**

!!! abstract "なぜ RR と IRR はずれるのか"
    リスクには **1 という天井**があります。
    発生が多い群ほど分母（リスク集団）が早く痩せるので、
    リスクは頭打ちになりやすい。

    率にはその天井がありません。
    したがって**アウトカムが多いほど、\(RR\) は \(IRR\) より 1 に近づきます。**

    発生がまれなときは、両者はほとんど一致します。

雪野が尋ねた。

> 「じゃあ、どっちを報告すればいいんですか」

> 「**追跡の長さが人によって違うなら率**、
> 全員を同じ期間追えたならリスクでよい」とロマンス先生。
> 「大事なのは**どちらを使ったか書くこと**です。
> 2.18 と 2.50 のどちらも正しく、どちらも別のことを言っています」

---

## 有病割合比（PR）は、RR の代わりにならない

[4-5](ch04-05.md) の二つの集団を思い出してください。

| | 発生率 \(IR\) | 罹病期間 \(D\) | 有病割合 \(P\) |
|---|---|---|---|
| 恋ヶ丘大学の学生 | 0.20 /人年 | 0.5年 | 9.1 % |
| 附属高校の生徒 | 0.10 /人年 | 2.0年 | 16.7 % |

| 指標 | 値 | 向き |
|---|---|---|
| 有病割合比 \(PR\) | **1.83** | 附属高校のほうが**多い** |
| 発生率比 \(IRR\) | **0.50** | 附属高校のほうが**少ない** |

!!! danger "比が逆を向く"
    **同じ二つの集団で、\(PR\) と \(IRR\) が反対方向を指しています。**

    有病割合には罹病期間 \(D\) が掛かっているからです。

    $$
    \frac{P}{1-P} = IR \times D
    $$

    \(PR\) が 1 より大きいとき、それは
    「発生が多い」のか「治りにくい」のか、**\(PR\) だけでは決して分かりません。**

    **原因を語るなら、有病割合比を持ち出さないこと。**

---

## オッズ比（OR）について一言

比較の指標には、もう一つ**オッズ比**があります。

$$
OR = \frac{32/48}{22/98} = \frac{0.667}{0.224} = 2.97
$$

RR が 2.18 なのに、OR は **2.97**。かなり大きく出ています。

!!! warning "オッズ比はリスク比を誇張する"
    アウトカムがまれ（数 % 以下）なら \(OR \approx RR\) です。
    これを**希少疾病近似（rare disease assumption）**と呼びます。
    しかしここでは 40 % と 18 % ― まったくまれではありません。
    その結果、OR は RR より 1 から遠い値になります。

    **オッズ比を「〜倍」と読み替えて説明してはいけません。**
    「合コンに出た人は 2.97倍恋に落ちる」は誤りです（正しくは 2.18倍）。

    オッズ比が主役になるのは、ケースコントロール研究など、
    リスクを直接計算できない設計のときです（第3章）。

---

## そして、この 2.18 は「効果」なのか

雪野が勝ち誇る。

> 「2.18倍！ **合コンには効果があります**」

ロマンス先生は静かに言った。

> 「いいえ。**合コンに出る人と出ない人が、そもそも違う人たち**だとしたら？」

> 「……えっ」

> 「恋愛に積極的な人ほど、合コンに出たくなる。
> そして恋愛に積極的な人ほど、合コンに出なくても恋に落ちる。
> **その場合、2.18 のうちどこまでが合コンのぶんか、この表からは分かりません。**」

ここまでで測れたのは**関連（association）**であって、**効果（effect）**ではありません。
2.18 を「合コンの効果」と呼べるのは、出た群と出なかった群が
**合コン以外の点で交換可能**なときだけです。

その条件を扱うのが第6章です。
もっとも、まず正しく測れなければ、交絡の議論にも進めません。

## 手を動かす

=== "Python"

    ```python
    a, n1, pt1 = 32,  80,  64.0   # 曝露あり: 件数, 人数, 人年
    b, n0, pt0 = 22, 120, 110.0   # 曝露なし

    R1, R0 = a / n1, b / n0
    IR1, IR0 = a / pt1, b / pt0

    print("R1, R0  :", round(R1, 4), round(R0, 4))     # 0.4 0.1833
    print("RR      :", round(R1 / R0, 3))              # 2.182
    print("IR1,IR0 :", round(IR1, 3), round(IR0, 3))   # 0.5 0.2
    print("IRR     :", round(IR1 / IR0, 3))            # 2.5

    OR = (a / (n1 - a)) / (b / (n0 - b))
    print("OR      :", round(OR, 3))                   # 2.97
    ```

=== "R"

    ```r
    a <- 32; n1 <- 80;  pt1 <- 64.0
    b <- 22; n0 <- 120; pt0 <- 110.0

    R1 <- a / n1; R0 <- b / n0
    IR1 <- a / pt1; IR0 <- b / pt0

    cat("R1, R0  :", round(R1, 4), round(R0, 4), "\n")   # 0.4 0.1833
    cat("RR      :", round(R1 / R0, 3), "\n")            # 2.182
    cat("IR1,IR0 :", round(IR1, 3), round(IR0, 3), "\n") # 0.5 0.2
    cat("IRR     :", round(IR1 / IR0, 3), "\n")          # 2.5

    OR <- (a / (n1 - a)) / (b / (n0 - b))
    cat("OR      :", round(OR, 3), "\n")                 # 2.97
    ```

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　どの比なのか書かない"
    「2.18倍」だけでは、RR なのか IRR なのか OR なのか分かりません。
    値も解釈も違います。**指標名を必ず添える。**

!!! failure "誤り2　オッズ比を「〜倍」と読む"
    アウトカムがまれでないとき、OR は RR より 1 から遠くなります。
    2.97 を「2.97倍恋に落ちる」と説明したら、それは 36 % の水増しです。

!!! failure "誤り3　有病割合比で原因を語る"
    \(PR\) には罹病期間が混ざっています。
    附属高校の例では、\(PR = 1.83\) と \(IRR = 0.50\) が**正反対を向いていました**。

## この回に出てきた用語

| 用語 | English | この回での意味 |
|---|---|---|
| リスク比 | risk ratio (RR) | 合コンに出た人と出なかった人のリスクの比 |
| 発生率比 | incidence rate ratio (IRR) | 同じく発生率の比 |
| 有病割合比 | prevalence ratio (PR) | 有病割合どうしの比 |
| オッズ比 | odds ratio (OR) | オッズどうしの比 |
| 希少疾病近似 | rare disease assumption | アウトカムがまれなら OR ≒ RR |
| 曝露 | exposure | 合コンに出たかどうか |
| 関連 | association | 数字の上での関係 |
| 効果 | effect | 合コンそのものが起こした変化 |

## 練習問題

**問1**　次のうち、RR = 1 が意味することとして正しいのはどれか。

1. 曝露と発生に関連がない
2. 発生がまったく起きていない
3. 曝露群のリスクが 100 % である
4. 効果がないことが証明された

??? success "解答"
    **1。**

    比の基準値は 0 ではなく **1** です。1 なら両群のリスクが等しい、
    つまり数字の上では関連がありません。

    4 は言い過ぎです。関連がないことと、
    **効果がないことが証明された**ことは別です（交絡が打ち消しあっている可能性もある）。
    また、推定値が 1 ちょうどでも、その周りの不確かさの幅は残ります（第5章）。

---

**問2**　あるコホートで、RR = 2.18、IRR = 2.50 だった。
この二つがずれた理由として最も適切なのは。

1. 計算間違い
2. アウトカムがまれではなく、リスクに天井があるため
3. 曝露の定義が群で違うため
4. 有病割合が混ざっているため

??? success "解答"
    **2。**

    リスクは 1 を超えられないので、発生が多い群ほど頭打ちになります。
    その結果、\(RR\) は \(IRR\) より 1 に近づきます。

    ここでは曝露群のリスクが 40 % もあるので、ずれがはっきり出ました。
    アウトカムがまれなら、両者はほぼ一致します。

---

**問3**　「合コンに出た人のほうが恋に落ちるリスクが 2.18倍」と分かった。
これを「合コンには恋を生む効果がある」と結論してよいか。30〜50字で。

??? success "解答例"
    **「よくない。合コンに出る人はもともと恋愛に積極的かもしれず、関連と効果は別だから」**

    測れたのは**関連**です。
    それを**効果**と呼ぶには、二つの群が合コン以外の点で交換可能である必要があります。
    その検討が第6章（交絡）です。

---

!!! quote "次回予告 ― 4-8 効果の測り方②　差と「益」"
    2.18倍。ではこの大学で、**何人を呼べば一組の恋が増えるのか**。
    比では絶対に答えられないこの問いに、**差**が答えます。
