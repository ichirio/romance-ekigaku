# 恋ヶ丘電鉄 ― 沿線と登場人物

起点の恋ヶ丘から、終点の成就まで、全8駅。
どの駅にも恋の事情があり、そのどれもが疫学の論点になっている。

---

## 沿線案内

### 1. 恋ヶ丘（こいがおか）

起点。恋ヶ丘大学があり、春には毎年ひとかたまりの新入生が改札を通る。
思い立ったその日に告白してしまう気風で、片思いが長続きしない。

同じ日に入学した同じ顔ぶれを、そのまま一年追える。
**閉鎖集団**と**リスク**の話は、この駅から始まる。

### 2. 待合（まちあい）

改札前の待ち合わせ場所が沿線一有名で、いつも誰かが誰かを待っている。
住民の出入りが激しく、誰がいつから沿線にいるのかがまちまち。

一人ひとり観察できた長さが違うとき、分母をどうするか。
**人時（person-time）**と**発生率**の舞台。

### 3. 片思ヶ丘（かたおもいがおか）

言い出せない街。片思いが何年も続く。
だから、いつ写真を撮っても片思い中の人がたくさん写る。

**有病割合**を**発生率**と読み違えるという、この章で最大の落とし穴がここにある。

### 4. 易者町（えきしゃまち）

占い館「**易の間（えきのま）**」の本店がある街。沿線各駅の支店を束ねている。
「易の間に通ったかどうか」が、この記録の主要な**曝露**になる。

曝露が薬やワクチンだと、読む前から結論を持ってしまう人が多い。
占いなら誰も結論を持っていないので、**測り方だけに集中できる**。

### 5. 相生（あいおい）

交際が長続きする街。始まった関係がなかなか終わらない。
**罹病期間**が有病割合を押し上げるとどうなるか、その実例。

### 6. 縁切坂（えんきりざか）

別れの多い坂の街。同じ人が一年に何度も恋をして、何度も失恋する。
**繰り返す事象**をどう数えるか。

### 7. 推町（おしまち）

推し活の聖地。大きなホールとグッズ店が並び、
ここで幸せに恋愛市場から降りていく人が毎年一定数いる。

追跡が途中で終わることの意味 ― **打ち切り**と**競合リスク**。

### 8. 成就（じょうじゅ）

終点。ここまで来ると、何かが決まる。

## 恋ヶ丘スタディ

沿線住民を追跡する観察研究を **恋ヶ丘スタディ（Koigaoka Romance Study, KRS）** という。
記録に出てくる数字は、すべてこの研究のものである（もちろん架空の研究である）。

数える対象は次のとおり。

| 恋ヶ丘での言い方 | 種類 |
|---|---|
| 恋に落ちる | **事象**（一瞬の出来事） |
| 「これは恋だ」と自覚する | **事象** |
| 恋煩いの最中である | **状態**（続いているもの） |
| 交際が始まる | **事象** |
| 失恋する・成就する | **事象** |
| 推し活に目覚めて恋愛市場を降りる | 事象（ただし競合リスク） |

事象を数えるのが**発生**、状態を数えるのが**有病**。
この二つを取り違えることが、第4章でいちばん潰したい誤りである。

## 登場人物

### 路須万 縁（ろすま ゆかり）教授

恋ヶ丘大学 疫学講座。通称**ロマンス先生**。

恋の話になると早口になるが、定義には一切妥協しない。
学生が数字を持ってくると、最初に必ずこう言う。

> 「その分母、なんですか？」

もう一つの口癖。

> 「**期間を言わないリスクは、行き先を言わない切符です。**」

有意差の有無で物事を決めることを、はっきり嫌っている。

### 占部 みくじ（うらべ みくじ）

学部3年。占いが大好きで、素直で、行動力がある。
いつも誰よりも早くデータを持ってきて、そして毎回、**相関を因果と読み違える**。

この記録のほとんどの回は、みくじの勘違いから始まる。

### 鉄村 定時（てつむら さだとき）

学部3年。鉄道オタクで記録魔。沿線住民の乗車履歴を秒単位で持っている。
みくじが「5人中3人」と言うたびに、静かに手帳を開いてこう言う。

> 「その5人、いつからいつまで数えた？」

分母と時間の番人。人時の計算はいつも彼が引き受ける。

### 有意 差子（ゆうい さこ）助教

何でも p 値で決めたがる。
「有意差が出ませんでした、つまり効果はありません」と言っては、
ロマンス先生に穏やかに論破される。

推定と検定の対比を持ち込む係。第5章で本格的にぶつかる。
