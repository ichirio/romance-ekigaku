# 世界の設定 ― 恋の病、沿線、登場人物

このページは、記事を書くとき／読むときに参照する設定資料です。
**恋の病は題材、疫学は中身。** ここで決めた設定は、疫学の定義を曲げるためではなく、
定義を身体で分かるために存在します。

---

## タイトルの由来

ロスマンの『疫学 ― 科学的思考への誘い』を、こうもじりました。

- **ロスマン** → **ロマンス**（ロ・ス・マ・ン のアナグラム）

**もじりはここだけです。「疫学」はそのまま。**

かつて「えき学（疫・易・駅・益）」案も検討しましたが、却下しました。
理由は二つ。**(1)** 読者が「どの"えき"だ？」と考えるコストを毎回払わされる。
**(2)** 〈疫学用語を恋に乗せる作業〉と〈えきのダジャレを回す作業〉の二重管理になる。
題材を**恋の病**に一本化すれば、疫学の語彙が一語も改造せずに乗ります。
そちらのほうが、笑いも教材価値も高い。

!!! note "易と駅は、小道具として残す"
    看板から降ろしただけで、捨ててはいません。
    **占い館「易の間」＝曝露**（読者が結論を持っていない題材なので、
    「まず測る」という手続きだけに集中できる）。
    **鉄道＝人時の舞台**（定期券の有効期間、途中乗車、途中下車が、
    そのまま観察期間・途中参入・打ち切りになる）。
    看板を降ろした分、義理で回さなくてよくなり、かえって自由に使えます。

## 疾病の定義：恋の病

この本が数える「病気」です。**定義を曖昧にしたまま数え始めないこと**が、
第4章の最初の教えでもあります。

| 疫学の言葉 | 恋の病では | 種類 |
|---|---|---|
| 疾病 disease | 恋の病（恋煩い） | ― |
| 感受性者 susceptible | 恋に落ちうる人 | 集団 |
| 免疫がある immune | いまは恋愛に関心がない人（分母から外れる） | 集団 |
| 曝露 exposure | 占い館「易の間」に通う／学園祭に行く | 要因 |
| 罹患・発生 incidence | 恋に落ちる | **事象** |
| 潜伏期 incubation period | 出会ってから自覚するまでの時間 | 時間 |
| 発症 onset | 「これは恋だ」と自覚した瞬間 | **事象** |
| 有病 prevalence | いま恋煩いの最中である | **状態** |
| 罹病期間 duration | 片思いが続いた長さ | 時間 |
| 治癒 recovery | 成就する／諦める | **事象** |
| 再感染 reinfection | また別の人に恋をする | **事象** |
| 流行 epidemic | 学園祭シーズンの恋の多発 | 集団現象 |
| 風土病 endemic | 季節によらず一定数いる片思い | 集団現象 |
| 予後 prognosis | 成就か、失恋か | ― |

!!! danger "この本で一番大事な区別"
    **「恋に落ちる」は事象（一瞬）、「恋煩い中である」は状態（続く）。**
    前者を数えるのが発生（incidence）、後者を数えるのが有病（prevalence）。
    この二つを取り違えることが、第4章で潰したい最大の誤りです。

!!! note "念のため"
    恋を病気に見立てるのは、恋が悪いものだという意味ではありません。
    疫学の道具が「集団の中で起きる出来事を数える道具」であることを見せるための見立てです。

## パロディの範囲（この本の憲法）

1. **もじるのは、タイトルと舞台と語り口だけ。**
2. **疫学の定義・指標・注意点は一切いじらない。** ロスマン第4章に忠実に書く。
3. 各記事の末尾に必ず **[用語対照表](glossary.md)** を置き、読者がいつでも
   本物の教科書に戻れるようにする。
4. 占いは**茶化す対象ではなく、研究対象**として扱う。効く／効かないを先に決めず、
   測り方の問題として真面目に扱う。その態度自体が疫学の教育である。

笑いは「厳密な手法が、恋という馬鹿馬鹿しい題材に大真面目に適用されること」の
ギャップから出ます。手法を茶化すと、笑いと教材価値が同時に死にます。

!!! danger "用語についての鉄則"
    **統計・疫学の用語は、一語たりともパロディにしない。**
    パロディにしてよいのは、**サンプルデータのテーマ（恋、占い、鉄道）だけ**。

    沿線の符牒（「恋人年」「御利益の人数」など）を使うことはあっても、
    **必ずその場で正式名称（人年、治療必要数 NNT）を併記し、正式名称を主とする。**
    造語を正式用語のように使わないこと。

    笑いは目的ではなく、疫学を学ぶための潤滑油にすぎない。
    どちらを削るか迷ったら、**必ず笑いのほうを削る。**

## 舞台：恋ヶ丘電鉄

私鉄・**恋ヶ丘電鉄（こいがおかでんてつ）**、全8駅。
沿線住民を追跡する観察研究を **恋ヶ丘スタディ（Koigaoka Romance Study, KRS）** と呼びます。

| # | 駅名 | 街の性格 | この駅が担当する疫学の論点 |
|---|---|---|---|
| 1 | **恋ヶ丘**（こいがおか） | 起点。恋ヶ丘大学がある。思ったらすぐ告白する気風 | 閉鎖集団・リスク（発生割合） |
| 2 | **待合**（まちあい） | 駅の待ち合わせ場所が有名。とにかく待つ人が多い | 人時（person-time）・発生率 |
| 3 | **片思ヶ丘**（かたおもいがおか） | 言い出せない街。片思いが何年も続く | 有病割合と発生率の混同 |
| 4 | **易者町**（えきしゃまち） | 占い館「易の間」の総本山。沿線各駅に支店を持つ | 曝露の定義と測定 |
| 5 | **相生**（あいおい） | 交際が長続きする街 | 罹病期間 D と有病割合 |
| 6 | **縁切坂**（えんきりざか） | 別れが多い坂の街 | 再発・繰り返す事象 |
| 7 | **推町**（おしまち） | 推し活の聖地。恋愛市場から幸せに離脱する人が多い | 競合リスク（competing risk） |
| 8 | **成就**（じょうじゅ） | 終点。ここまで来ると何かが決まる | 追跡の完了・打ち切り |

!!! tip "なぜ鉄道なのか（設計意図）"
    疫学でいちばん躓くのは **分母** です。鉄道は分母の直感を無料でくれます。
    定期券には**有効期間**があり、乗客は**途中の駅から乗り**、**途中の駅で降ります**。
    これはそのまま「観察期間」「途中参入」「打ち切り」です。
    人時（person-time）を「延べ乗車時間」として説明できるのは、この舞台の最大の利点です。

## 登場人物

### 路須万 縁（ろすま ゆかり）教授 ― 通称「ロマンス先生」

恋ヶ丘大学 疫学講座。恋の話になると早口になるが、定義には一切妥協しない。
学生が数字を持ってくると、必ず最初にこう言う。

> 「その分母、なんですか？」

もう一つの口癖。

> 「**期間を言わないリスクは、行き先を言わない切符です。**」

役割：正しい定義を述べる人。ロスマンの立場（有意性検定への批判を含む）を代弁する。

### 占部 みくじ（うらべ みくじ） ― 学部3年

占いが大好き。素直で行動力があり、いつも先にデータを持ってくる。
そして毎回、**相関を因果と読み違える**。この本のすべての回は、
だいたいみくじの勘違いから始まります。

役割：読者の代理。よくある誤りを、悪びれずに口に出してくれる人。

### 鉄村 定時（てつむら さだとき） ― 学部3年

鉄道オタクで記録魔。沿線住民の乗車履歴を秒単位で持っている。
みくじが「5人中3人」と言うたびに、静かに手帳を開いてこう言う。

> 「その5人、いつからいつまで数えた？」

役割：分母と時間の番人。人時の計算はいつも彼が引き受ける。

### 有意 差子（ゆうい さこ）助教

何でも p 値で決めたがる。「有意差が出ませんでした、つまり効果はありません」と言っては、
ロマンス先生に穏やかに論破される。

役割：**推定 vs 検定**の対比を持ち込む係。ロスマンが有意性検定に批判的であることの
内輪ネタであり、第5〜6章（推定・区間・精度）への伏線でもあります。

## 曝露：占い館「易の間」

各駅前にある占い館。チェーン店で、本店は易者町。
「易の間に通ったかどうか」が、この本の主要な**曝露**です。

- 曝露あり：追跡開始から1年のあいだに1回以上、易の間で恋愛について占ってもらった
- 曝露なし：一度も行っていない

!!! note "なぜ占いを曝露にするのか"
    曝露が薬やワクチンだと、読者は「効くに決まっている／効かないに決まっている」という
    先入観を持ちます。占いは**読者が結論を持たない**ので、
    「まずデータで測る」という手続きだけに集中できます。
    そして第6章では、これが交絡（占いに行く人はそもそも恋愛に積極的では？）の
    完璧な教材になります。

## 記事の固定フォーマット

すべての回を、この順番で書きます。

1. **導入場面（見出しなし）** ― 沿線の日常のひとこま。短く。
   **「掴み」のような見出しは付けない。**目次に並ぶと「ここは笑うところ」という
   宣言になってしまい、学習の邪魔になる。場面はそのまま本文として置く。
2. **素朴な疑問** ― みくじの勘違い
3. **定義** ― ロマンス先生。ここはロスマン準拠で厳密に
4. **手を動かす** ― 架空データ＋ Python / R のコード。**数値は必ず実行して検証する**
5. **ロマンス先生の赤ペン ― よくある誤り** ― 3つ
6. **用語対照表** ― 恋の病の言い方 ↔ 疫学正式用語 ↔ 英語
7. **練習問題** ― 解答つき

!!! warning "執筆時の絶対ルール"
    記事中のすべての数値は、掲載前に必ずコードで計算して確認すること。
    「だいたいこのくらい」で書かない。この本は疫学の教材であり、
    数字が合っていないパロディは、ただのパロディです。
