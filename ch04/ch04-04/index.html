    4-4　リスクと率は、どこが違うのか¶

    恋都大学　― 二つの指標の関係、短期近似とその限界

    雪野が、二つの数字を並べて唸っていた。

    「新入生の1年リスクは 29.0 %。サークルの発生率は 23.3 件/100人年。 ……これ、どっちが恋が生まれやすいんですか？」

    ロマンス先生は黒板に大きく書いた。

    「単位の違う数字を、そのまま比べてはいけません。 でも、変換はできます」

    二つは何が違うのか¶

    リスク \(R\) 発生率 \(IR\)
    問い 「期間内に起きるか」 「どれだけ速く起きるか」
    分母 人数 人時
    範囲 0 〜 1 0 〜 ∞
    単位 なし 1/時間
    たとえ 目的地に着いたか 時速

    ロマンス先生の比喩

    「率は速度、リスクは到達したかどうかです。 時速 40 km で走っている車が、1時間後にどこにいるか。 ふつうは 40 km 先です。ただし、途中で止まらなければ」

    つなぐ式¶

    率が期間中ずっと一定だと仮定すると、リスクと率はこう結ばれます。

    \[ R = 1 - e^{-IR \times T} \]

    そして、\(IR \times T\) が小さいとき（おおむね 0.1 以下）、これは次のように近似できます。

    \[ R \approx IR \times T \]

    これが「率 × 期間 ≒ リスク」という、実務で最もよく使う関係です。

    なぜ引き算になるのか

    \(e^{-IR \times T}\) は「期間 T のあいだ、一度も発生しなかった確率」です。 リスクはその余事象、つまり「1回以上発生した確率」。だから 1 から引きます。

    率が高くても、リスクは決して 1 を超えません。 「速く走っても、目的地は一つしかない」からです。

    サークルの10人で確かめる¶

    前回の発生率は \(IR = 0.2326\) /人年 でした。これを各期間のリスクに直します。

    期間 \(T\) 近似 \(IR \times T\) 率一定モデル \(1 - e^{-IR \times T}\) ずれ
    1年 23.3 % 20.7 % 2.5 ポイント
    2年 46.5 % 37.2 % 9.3 ポイント
    5年 116.3 % 68.7 % 47.5 ポイント

    5年の行を見てください

    近似が 116.3 % になっています。リスクが 100 % を超えました。

    これは近似が壊れたサインです。 率は 0〜∞ ですが、リスクは 0〜1。 掛け算をそのままリスクと呼べるのは、値が小さいうちだけです。

    雪野が青ざめた。

    「じゃあ、私が『5年で 116 % の確率で恋に落ちます』って言ってたのは……」

    「日本語としても間違っています」とロマンス先生。

    なぜずれるのか ― 分母が痩せていく¶

    近似 \(R \approx IR \times T\) は、 「分母（リスク集団）が期間中ずっと減らない」と仮定しています。

    しかし実際には、恋に落ちた人は次々にリスク集団から抜けていきます。 残った人が少なくなるほど、新しい発生は起こりにくくなる。 だから現実のリスクは、掛け算よりも小さくなるのです。

    時間 →
リスク集団 ████████████████████  100人（開始時）
              ███████████████   ↓ 恋に落ちた人が抜けていく
                 ████████████
                    █████████   残った人だけが「次の発生」を担う

    期間が短ければ抜ける人はわずかなので、掛け算でよく合います。 期間が長くなると無視できなくなります。

    実務での目安

    \(IR \times T\) が 0.1（＝リスク約10 %）以下なら、近似のずれは1割未満です。 それを超えるなら、指数の式を使うか、そもそもリスクではなく率で報告する。

    で、どちらが恋に落ちやすいのか¶

    冒頭の雪野の問いに答えます。単位を揃えれば比べられます。

    集団 もとの数字 1年リスクに揃えると
    新入生コホート 1年リスク 29.0 % 29.0 %
    軽音サークル 23.3 件/100人年 \(1 - e^{-0.2326}\) ＝ 20.7 %

    新入生のほうが高い。 これでようやく、比較らしい比較になりました。

    ただし、これは「比べられる形にした」だけ

    新入生はほぼ全員18歳で独身、サークルには1年生から4年生までいます。 数字の形が揃っても、集団が違えば比較は成立しません。 これが第6章（交絡）と標準化の話につながります。

    手を動かす¶

    import math
import pandas as pd

IR = 5 / 21.5  # 前回の発生率（/人年）

tbl = pd.DataFrame({"T": [1, 2, 5]})
tbl["approx"] = IR * tbl["T"]
tbl["exact"]  = 1 - (-IR * tbl["T"]).apply(math.exp)
tbl["gap_pt"] = (tbl["approx"] - tbl["exact"]) * 100

print(tbl.round(4))
#    T  approx   exact  gap_pt
# 0  1  0.2326  0.2075    2.51
# 1  2  0.4651  0.3719    9.32
# 2  5  1.1628  0.6874   47.54

    IR <- 5 / 21.5

tbl <- data.frame(T = c(1, 2, 5))
tbl$approx <- IR * tbl$T
tbl$exact  <- 1 - exp(-IR * tbl$T)
tbl$gap_pt <- (tbl$approx - tbl$exact) * 100

print(round(tbl, 4))
#   T approx  exact  gap_pt
# 1 1 0.2326 0.2075  2.5140
# 2 2 0.4651 0.3719  9.3239
# 3 5 1.1628 0.6874 47.5372

    ロマンス先生の赤ペン ― よくある誤り¶

    誤り1　率をそのままリスクとして報告する

    「発生率 23.3 件/100人年」を「1年で 23.3 % の人が恋に落ちる」と書き換えるのは、 近似であって等式ではありません。正しくは 20.7 % です。 短期なら実害は小さいですが、近似だと書かずに使わないこと。

    誤り2　100 % を超えた数字をそのまま出す

    リスクが 100 % を超えたら、計算ではなく手法の選択が間違っています。 その期間にはリスクではなく率を使うべきです。

    誤り3　単位の違う数字を並べて「こっちが高い」と言う

    29.0 %（リスク）と 23.3 件/100人年（率）は、そのままでは大小を比べられません。 どちらかに揃えてから比べる。揃えられないなら比べない。

    この回に出てきた用語¶

    用語 English この回での意味
    リスクと率の近似関係（発生がまれなとき） risk-rate approximation 率 × 期間 ≒ リスク
    生存確率 survival probability 一度も恋に落ちない確率
    分母の減少 depletion of susceptibles 恋に落ちた人がリスク集団から抜ける
    ハザード一定の仮定 constant hazard assumption 率が期間中ずっと一定

    練習問題¶

    問1　ある集団の発生率は 0.05 /人年だった。 1年リスクを (a) 近似で (b) 率一定モデルで 求めよ。

    解答

    (a) 近似：\(0.05 \times 1 = 0.05\) ＝ 5.0 %

    (b) 率一定モデル：\(1 - e^{-0.05} = 0.04877\) ＝ 4.9 %

    ずれは 0.1 ポイント。この程度なら近似で十分実用的です。 \(IR \times T\) が小さいときは、両者はほとんど一致します。

    問2　雪野が言った。 「発生率が 2.0 /人年なので、1年リスクは 200 % です」 どこが間違っているか。また正しい値は。

    解答

    リスクは 1（100 %）を超えられません。 近似の適用範囲を大きく外れています。

    正しくは \(1 - e^{-2.0} = 0.8647\) ＝ 86.5 %。

    なお「率が 2.0 /人年」自体は何もおかしくありません。 平均して1人が1年に2回恋をする勢い、という意味です。 率は 1 を超えてよく、リスクは超えてはいけない ― この非対称が、二つが別の量である何よりの証拠です。

    問3　なぜ「率 × 期間」は本当のリスクより大きくなるのか。40字程度で。

    解答例

    「恋に落ちた人がリスク集団から抜けていく分を、掛け算は無視しているから」

    掛け算は分母がずっと一定だと仮定しています。 実際には発生するたびに分母が痩せるので、 後半ほど新しい発生は起きにくい。だから現実は掛け算より小さくなります。

    次回予告 ― 4-5 片思いの有病割合　一番危ない勘違い

    ここまでは「恋が生まれる」話でした。 次回は「いま片思い中である」という、まったく別の量を扱います。 そして、この章で一番危ない勘違いを、数字で分解します。
