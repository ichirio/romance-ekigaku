# 用語集

第4章に出てくる用語の一覧です。意味の欄には、恋都スタディでの例を添えてあります。

---

## 恋の病の自然史

| 用語 | English | 意味 |
|---|---|---|
| 感受性者 | susceptible | これから恋に落ちうる人 |
| 免疫がある | immune | いまは恋愛に関心がなく、分母に入らない人 |
| 曝露 | exposure | 合コンに出る、学園祭に行く |
| 潜伏期 | incubation period | 出会ってから自覚するまでの時間 |
| 発症 | onset | 「これは恋だ」と自覚した瞬間 |
| 罹患・発生 | incidence | 恋に落ちるという事象 |
| 有病 | prevalence | 恋の病にかかっている状態。片思い期と恋愛期がある |
| 罹病期間 | duration | 片思いが続いた長さ |
| 寛解・治癒 | recovery | 振られる、諦める、別れる。**成就は含まない**（病期が変わるだけ） |
| 再感染 | reinfection | また別の人に恋をする |
| 流行 | epidemic | 学園祭シーズンの恋の多発 |
| 予後 | prognosis | 寛解して戻るか、結婚して終点に至るか |

## 集団と時間

| 用語 | English | 意味 |
|---|---|---|
| 研究集団 | study population | 恋都スタディの参加者 |
| リスク集団 | population at risk | 発症していない人。片思い中・交際中の人は入らない |
| 閉鎖集団 | closed population | 2026年4月入学の新入生200人。途中から誰も入らない |
| 開放集団（動的集団） | open / dynamic population | 軽音サークルの部員。出入りがある |
| 人時 | person-time | 恋に落ちうる状態でいた時間の、全員ぶんの合計 |
| 人年 | person-year | 人時の単位のひとつ |
| 打ち切り | censoring | 留学・退学などで追跡が途切れること。事象ではない |
| 競合リスク | competing risk | 推し活への移行など、もう発生しえないと定めた事象 |
| 無情報打ち切り | non-informative censoring | 降りた人も残った人と同じだった、という前提 |

## 発生の指標

| 用語 | English | 値の範囲・単位 | 意味 |
|---|---|---|---|
| リスク（累積発生割合） | risk / cumulative incidence | 0〜1・無単位（**期間が必須**） | 1年以内に恋に落ちた人の割合 |
| 発生率（罹患率） | incidence rate | 0〜∞・1/時間 | 人年あたり何件の恋が生まれるか |
| 有病割合 | prevalence | 0〜1・無単位 | ある時点で片思い中の人の割合 |
| 罹病期間 | duration (\(D\)) | 時間 | 片思いが続く平均の長さ |

有病割合は、発生率と罹病期間の両方で決まります。定常状態では \(P/(1-P) = IR \times D\)。

## 効果の指標

| 用語 | English | 基準値 | 意味 |
|---|---|---|---|
| リスク比 | risk ratio (RR) | 1 | 合コンに出た人と出なかった人のリスクの比 |
| リスク差 | risk difference (RD) | 0 | 同じくリスクの差 |
| 発生率比 | incidence rate ratio (IRR) | 1 | 発生率の比 |
| 有病割合比 | prevalence ratio (PR) | 1 | 有病割合の比。**リスク比の代用にはならない** |
| オッズ比 | odds ratio (OR) | 1 | オッズの比。まれでないとリスク比を誇張する |
| 希少疾病近似 | rare disease assumption | ― | アウトカムがまれなら OR ≒ RR |
| 治療必要数 | number needed to treat (NNT) | ― | 一組ぶん増やすのに何人必要か。1÷リスク差 |
| 寄与危険割合 | attributable fraction | 0 | 曝露群の発生のうち、曝露に帰せられる割合 |
| 集団寄与危険割合 | population attributable fraction | 0 | 集団全体の発生のうち、曝露に帰せられる割合 |

## 解釈と報告

| 用語 | English | 意味 |
|---|---|---|
| 関連 | association | 数字の上での結びつき |
| 効果 | effect | 曝露そのものが起こした変化 |
| 交絡 | confounding | 合コンに出る人はそもそも恋愛に積極的では？ という問題 |
| 偏り（バイアス） | bias | 推定値が真の値から系統的にずれること |
| 区間推定 | interval estimation | 「どのくらい、どのくらいの幅で」 |
| 有意性検定 | significance testing | 「有意か否か」の二択。推定値の情報を捨てる |
| ハザード一定の仮定 | constant hazard assumption | 率が期間中ずっと変わらないという前提 |
