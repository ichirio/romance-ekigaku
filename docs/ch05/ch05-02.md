# 5-2　コホート研究 ― 曝露から出発して、待つ

> 閉鎖コホートと開放コホート、前向きと後ろ向き、そして代償

---

暦野定時が、ずっと持ち歩いている台帳を机に置いた。
恋ヶ丘スタディの 200人が、一行ずつ書き込まれたあの台帳である。

> 「先生。この台帳、そういえば**名前**はあるんですか」

> 「あります」とロマンス先生。「**コホート研究**です。
> しかも、いちばん素直な形の」

---

## コホート研究とは

**曝露で人を分けて、そのあとアウトカムが起きるかどうかを追いかける。**
それだけです。

```
          追跡開始                          追跡終了
             │                                 │
  占った80人  ├───────────────────────────▶  32件
             │
 占わない120人├───────────────────────────▶  22件
             │
             └─ ここで曝露を測る      ここまで恋の発生を数える
```

大事なのは**順番**です。曝露を先に確定させ、そのあとの発生を数える。
この向きが守られている限り、それはコホート研究です。

!!! note "コホートという言葉"
    もとはローマ軍の一隊を指す言葉で、
    疫学では「**一緒に時間を進んでいく人の集まり**」を指します。
    同じ年に入学した学生の一群、というときの「一群」がまさにそれです。

---

## 二つの形

第4章で出てきた区別が、そのまま設計の区別になります。

=== "閉鎖コホート"

    **一度決めたら、あとから誰も入らない。**

    例：2026年4月入学の新入生 200人。
    集団は減ることはあっても増えません。

    全員を同じ期間追えるので、**リスク（累積発生割合）**が計算できます。

=== "開放コホート"

    **出入りがある。**

    例：軽音サークルの部員。毎年入り、毎年卒業していきます。

    一人ひとり観察できた長さが違うので、
    分母を人数ではなく**人時**にして、**発生率**を計算します。

どちらもコホート研究です。**違うのは分母の作り方だけ**で、
「曝露から出発して発生を追う」という骨格は同じです。

---

## 直接得られるもの

コホート研究の強みは、ここに尽きます。

| 指標 | 得られるか | 第4章での値 |
|---|---|---|
| リスク \(R\) | **得られる** | 40.0 % / 18.3 % |
| 発生率 \(IR\) | **得られる**（人時があれば） | 0.500 / 0.200 /人年 |
| リスク比 \(RR\) | **得られる** | 2.18 |
| 発生率比 \(IRR\) | **得られる** | 2.50 |
| リスク差 \(RD\) | **得られる** | 21.7 ポイント |

**発生の絶対量が出せる**のが、この設計の最大の特徴です。
「占った人の 40 % が1年以内に恋に落ちた」と言えるのは、
分母である 80人を丸ごと把握しているからです。

このあと出てくる症例対照研究には、これができません。

---

## 前向きと後ろ向きは、別のデザインではない

みくじが手を挙げた。

> 「先生、**後ろ向きコホート研究**って聞いたことがあります。
> あれは症例対照研究のことですか」

> 「違います。**まったく別の話です**」

| 呼び方 | 何が違うのか |
|---|---|
| 前向きコホート prospective | 研究を始めてから、これからデータを取る |
| 後ろ向きコホート retrospective / historical | すでに存在する記録を使って、過去の時点から追う |

違うのは**データがいつ作られたか**だけです。
どちらも曝露を先に確定させ、そのあとの発生を数えます。
**追跡の向きは、常に曝露 → アウトカム。**

!!! danger "「後ろ向き」という言葉が混乱を生む"
    後ろ向きコホート研究は、**コホート研究**です。
    症例対照研究とはまったく別物です。

    たとえば「2015年の学籍簿と占い館の会員名簿を突き合わせ、
    2016年から2020年までの結婚届を数える」のは後ろ向きコホート研究。
    データはすべて過去にありますが、
    曝露を先に決めて発生を数えている以上、コホート研究です。

---

## 代償

強い設計ですが、ただではありません。

**全員の曝露を測らなければならない。**
200人に「易の間に行きましたか」と聞いて回る必要があります。
1年後に恋に落ちるのは 54人ですが、**残りの 146人にも同じ手間がかかります。**

**全員を追わなければならない。**
途中で降りる人が出れば、[4-6](../ch04/ch04-06.md) の打ち切りの問題が発生します。

**まれなアウトカムに弱い。**
1年で 2 % しか起きないことを調べたければ、
200人では 4件しか集まりません。分子が育たないのです。

**逆に、まれな曝露には強い。**
曝露群を狙って集められるからです。
易の間の会員名簿を使えば、利用者だけを確実に確保できます。

| | まれなアウトカム | まれな曝露 |
|---|---|---|
| コホート研究 | **苦手** | **得意** |
| 症例対照研究 | **得意** | 苦手 |

この非対称が、次回からの話の出発点になります。

---

## 手を動かす

第4章の台帳を、コホート研究の要約として組み立て直します。

=== "Python"

    ```python
    import pandas as pd

    cohort = pd.DataFrame({
        "exposure":     ["占った", "占わなかった"],
        "n":            [80, 120],      # 追跡開始時の人数
        "cases":        [32, 22],       # 1年で恋に落ちた件数
        "person_years": [64.0, 110.0],  # 観察人年
    })

    cohort["risk"] = cohort["cases"] / cohort["n"]
    cohort["rate"] = cohort["cases"] / cohort["person_years"]

    print(cohort.round(4))
    #        exposure    n  cases  person_years    risk  rate
    # 0          占った   80     32          64.0  0.4000   0.5
    # 1    占わなかった  120     22         110.0  0.1833   0.2

    e, u = cohort.iloc[0], cohort.iloc[1]
    print("RR  :", round(e["risk"] / u["risk"], 4))   # 2.1818
    print("IRR :", round(e["rate"] / u["rate"], 4))   # 2.5
    print("RD  :", round(e["risk"] - u["risk"], 4))   # 0.2167
    ```

=== "R"

    ```r
    cohort <- data.frame(
      exposure     = c("占った", "占わなかった"),
      n            = c(80, 120),
      cases        = c(32, 22),
      person_years = c(64.0, 110.0)
    )

    cohort$risk <- cohort$cases / cohort$n
    cohort$rate <- cohort$cases / cohort$person_years

    print(cohort)
    #       exposure   n cases person_years      risk rate
    # 1       占った  80    32           64 0.4000000  0.5
    # 2 占わなかった 120    22          110 0.1833333  0.2

    cat("RR  :", round(cohort$risk[1] / cohort$risk[2], 4), "\n")  # 2.1818
    cat("IRR :", round(cohort$rate[1] / cohort$rate[2], 4), "\n")  # 2.5
    cat("RD  :", round(cohort$risk[1] - cohort$risk[2], 4), "\n")  # 0.2167
    ```

第4章でひとつずつ組み立てた指標が、**同じ一枚の表からすべて出てきます。**
これがコホート研究の効きどころです。

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　後ろ向きコホート研究を症例対照研究と呼ぶ"
    データが過去にあるかどうかと、どこから出発するかは、別の話です。
    **曝露で分けて発生を数えているなら、それはコホート研究**です。

!!! failure "誤り2　アウトカムの後に測った曝露を使う"
    「恋に落ちた人に、いま占いに通っているか聞いた」では、順番が逆です。
    恋に落ちたから占いに行ったのかもしれません。
    **曝露はアウトカムより先に確定していなければならない。**

!!! failure "誤り3　追跡の長さが違うのに人数で割る"
    開放コホートで人数を分母にすると、
    3年見た人と半年しか見ていない人が同じ重みになります（[4-3](../ch04/ch04-03.md)）。
    分母を**人時**にする。

---

## この回に出てきた用語

| 用語 | English | 意味 |
|---|---|---|
| コホート研究 | cohort study | 曝露で分け、そのあとの発生を追う |
| 閉鎖コホート | closed cohort | 途中から誰も入らない。リスクが計算できる |
| 開放コホート | open cohort | 出入りがある。人時で発生率を計算する |
| 前向きコホート研究 | prospective cohort study | これからデータを取る |
| 後ろ向きコホート研究 | retrospective / historical cohort study | 既存の記録で過去の時点から追う。**症例対照研究ではない** |
| 追跡 | follow-up | 曝露を確定させたあと、発生を数える期間 |

## 練習問題

**問1**　次の研究はどの型か。
「2015年度の学籍簿と、易の間の 2015年の会員名簿を突き合わせた。
その 2 500人について、2016年から 2020年までの結婚届を数え、
会員だった人となかった人で比べた」

??? success "解答"
    **後ろ向き（歴史的）コホート研究。**

    データはすべて過去のものですが、
    **2015年の曝露で分けて、そのあとの発生を数えています。**
    曝露 → アウトカムの向きが守られているので、コホート研究です。

    症例対照研究ではありません。症例対照研究は、
    結婚した人を先に集めるところから始まります。

---

**問2**　1年で 2 % しか起きないアウトカムを、コホート研究で調べたい。
曝露群と非曝露群で 2倍の差があるとして、200人の追跡では何が起きるか。

??? success "解答"
    **分子が育たない。**

    曝露群 80人で 2.0 %、非曝露群 120人で 1.0 % と仮定すると、
    期待される発生件数は 80 × 0.02 = 1.6件 と 120 × 0.01 = 1.2件。
    **合わせて 3件足らず**です。

    この人数では、比の推定値は数件の増減で大きく揺れます。
    まれなアウトカムに対してコホート研究が苦手だ、というのはこの意味です。

    対処は二つ。**基盤を桁違いに大きくする**か、
    **症例対照研究に切り替える**か。次回はその後者の話です。

---

**問3**　開放コホートでリスク（累積発生割合）を計算しようとしている学生がいる。
何を確認すべきか。

??? success "解答"
    **全員を同じ期間、最後まで追えているかどうか。**

    追えているなら、その期間についてリスクを計算してかまいません。
    追えていない（途中参入・途中離脱がある）なら、
    リスクの分母が作れないので、**発生率を使う**か、
    率から期間を指定してリスクに変換します（[4-4](../ch04/ch04-04.md)）。

    いずれにせよ「1年リスク」と書くなら、**その1年を全員ぶん持っている**必要があります。
