    4-1　「恋に落ちた人」を数える前に¶

    恋都大学　― 事象と状態、リスク集団、閉鎖集団と開放集団

    京の都の北のはずれ、恋都大学。医学部棟の三階では、週に一度、 恋の病研究会という自主ゼミがひらかれている。 疫学の教授が勝手に始めたもので、学部は問わない。単位も出ない。

    その帰りの学食で、雪野順が、トレイを置くより先に言った。

    「先生、やっぱりうちの大学って、恋が生まれやすいんですよ。 だって私の友達、5人中3人に恋人ができたんです。60％ですよ、60％」

    ロマンス先生は、味噌汁を持ち上げかけた手を止めて、こう言った。

    「その分母、なんですか？」

    雪野の勘違い¶

    雪野の「60％」には、疫学が要求する三つのことが、どれ一つ書かれていません。

    1. 何を数えたのか（「恋人ができた」とは、いつ・どの状態になったことか）
    2. 誰の中で数えたのか（その5人は、どういう理由で選ばれた5人か）
    3. いつからいつまで数えたのか（1か月の話か、大学4年間の話か）

    疫学の指標は、例外なく次の形をしています。

    \[ \text{指標} = \frac{\text{何を数えたか}}{\text{誰の中で、どれだけの時間について数えたか}} \]

    分子より、分母のほうがずっと難しい。 この章はそのための章です。

    1. 何を数えるか ― 事象と状態を分ける¶

    恋の病について言えることは、大きく二種類あります。

    言い方 種類 疫学では
    「恋に落ちた」 事象（event）＝ 一瞬の出来事 発生・罹患 incidence
    「恋の病にかかっている」 状態（state）＝ 続いているもの 有病 prevalence
    「振られた」 事象 状態からの離脱（寛解）

    第4章で一番潰したい誤り

    「片思い中の人が多い」と「恋に落ちる人が多い」は、まったく別の話です。 前者は有病、後者は発生。 片思いが長引く集団では、新しい恋がほとんど生まれていなくても、 片思い中の人の割合はいくらでも高くなります（→ 4-5）。

    発生を数えるには「いつ発生したか」を決めねばならない¶

    恋の病には潜伏期（incubation period）があります。 好きになりはじめた時点と、「これは恋だ」と自覚した時点は違う。 ときには何か月も違う。

    結核と同じ形です。感染した日と発症した日は違い、 疫学は普通、観察できるほう（発症）を発生日として使います。

    恋都スタディも、そこに倣ってこう決めています。

    恋の病の発生日 ＝ 本人が「これは恋だ」と自覚した日（自己申告）

    出会った日ではありません。出会いは曝露であって、発症ではないからです。

    雪野が不満そうに言う。

    「自己申告なんて、当てになりますか？」

    「なりません」とロマンス先生。「だからそう定義したと明記するんです。 当てになる定義があるのではなく、書いてある定義があるだけです。 当てにならなさは第7章（誤分類）で正面から扱います。今は、 定義を書かずに数え始めないことだけ覚えてください」

    2. 誰の中で数えるか ― リスク集団¶

    分子に入りうる人だけが、分母に入れます。これがリスク集団（population at risk）です。 感染症の言葉では感受性者（susceptible）。

    恋の病でいえば、恋に落ちうる人です。

    追跡開始時点の状態 リスク集団に入るか 理由
    誰にも恋していない 入る これから恋に落ちうる
    すでに片思い中 入らない もう発症済み（有病者）
    すでに交際中 入らない 発症済み（恋の病の恋愛期にいる）
    いまは恋愛に関心がない 入らない 感染症でいう「免疫がある」状態

    麻疹の発生率を計算するとき、すでに免疫を持つ人を分母に入れたら、率は不当に小さくなります。 恋の病でもまったく同じで、「恋に落ちようがない人」を分母に入れると、恋は起きにくく見えます。

    恋の病には、二つの病期がある¶

    恋の病は、麻疹より風邪に近い病気です。何度でも罹ります。

    そして、かかっているあいだの状態は一つではありません。 片思い期と恋愛期。どちらも同じ病にかかっている状態で、病期が違うだけです。

                             ┌──恋の病（有病）──┐
進む   感受性 →[発症]→ 片思い期 →[成就]→ 恋愛期

別の入口   感受性 →[告白される]→ 恋愛期      ← 片思い期を経ないこともある

戻る   片思い期 →[振られる・諦める]→ 感受性
       恋愛期 →[別れる]────────────→ 感受性
    状態 恋の病か リスク集団にいるか
    感受性 かかっていない いる
    片思い期 有病 いない
    恋愛期（交際中） 有病 いない
    移り変わり 恋都での言い方 疫学での扱い
    感受性 → 片思い期 好きな人ができる 発症（incidence）。ここで数える主アウトカム
    感受性 → 恋愛期 告白されて付き合いはじめる 発症。片思い期を経ない入口
    片思い期 → 恋愛期 告白して成就する 病期の移行。治癒ではない
    片思い期 → 感受性 振られる／自分から諦める 寛解。リスク集団へ戻る
    恋愛期 → 感受性 別れる 寛解。リスク集団へ戻る

    成就は「治った」ではない

    告白が実っても、恋の病は治っていません。病期が変わっただけです。 片思い期から恋愛期へ移るだけで、リスク集団には戻りません。

    治る（寛解する）のは、振られたとき、諦めたとき、別れたときだけ。 身も蓋もない話ですが、この研究はそう数えると決めました。

    「片思いが終わった人数」をまとめて数えると、この区別が消えます。 終わり方が成就なら、その人はまだ有病のままです。

    つまりリスク集団のメンバーは、追跡の途中で出たり入ったりします。 これを厳密に扱う道具が、次々回に出てくる人時（person-time）です。

    この病に、終わりはない

    図に終点はありません。恋の病を二度と起こさなくする出来事が、ないからです。

    結婚しても終わりません。恋愛期が続いているだけで、別れればまた感受性に戻ります。 年をとっても終わりません。百歳で罹る人もいます。

    終わるのは、死んだときだけ ―― 疫学が競合リスクと呼ぶのは、 そういう出来事のことです（→ 4-6）。

    3. いつからいつまで ― 閉鎖集団と開放集団¶

    雪野の「5人」は、いつからいつまでの5人でしょうか。 ここで集団は二種類に分かれます。

    一度決めたら、あとから誰も入ってこない集団。

    例：2026年4月入学の新入生のうち、恋都スタディに参加した 200人。 2026年5月に転入してきた学生は、この集団には入りません。 集団は減ることはあっても（転出・追跡不能）、増えません。

    → 全員を同じ期間追えるので、リスク（累積発生割合）が計算できます。

    出入りが自由な集団。

    例：軽音サークルの部員。 毎年新入生が入り、毎年誰かが卒業し、途中で辞める人もいます。 「部員は何人」と言っても、それは今日の写真にすぎません。

    → 一人ひとりの在籍時間が違うので、リスクではなく 発生率（incidence rate）を使います。

    集団の形が決まれば、使える指標も決まります。 閉鎖集団ならリスク、開放集団なら発生率。 そしてこの二つがどうつながっているかは、その次の回で扱います。

    研究会でいちばん古参の小堀定時が、手帳を開いて静かに補足する。 日付の記録にかけては、この男の右に出る者がいない。

    「学籍には入った日と、抜けた日が必ず記録されています。 疫学が一人ひとりについて知りたいのは、結局それだけです。 いつリスク集団に入って、いつ出たか。」

    手を動かす¶

    恋都スタディの参加者から10人だけ取り出して、分母を間違えるとどうなるかを見ます。

    • baseline_partner … 追跡開始時点ですでに交際中か
    • fell_in_love … 追跡1年のあいだに恋に落ちたか（交際中の人は対象外なので欠測）
    import pandas as pd

krs = pd.DataFrame({
    "id": range(1, 11),
    "baseline_partner": [False, False, True, False, False,
                         False, True, False, False, False],
    "fell_in_love": pd.array([True, False, None, True, False,
                              False, None, True, False, False],
                             dtype="boolean"),
})

# 分母は「追跡開始時点で恋に落ちうる人」＝ リスク集団だけ
at_risk = krs[~krs["baseline_partner"]]

print("全参加者      :", len(krs))                                    # 10
print("リスク集団    :", len(at_risk))                                #  8
print("恋に落ちた    :", at_risk["fell_in_love"].sum())               #  3
print("正しいリスク  :", at_risk["fell_in_love"].sum() / len(at_risk))   # 0.375
print("間違えた分母  :", krs["fell_in_love"].sum() / len(krs))           # 0.3

    krs <- data.frame(
  id      = 1:10,
  baseline_partner = c(FALSE, FALSE, TRUE, FALSE, FALSE,
                       FALSE, TRUE,  FALSE, FALSE, FALSE),
  fell_in_love     = c(TRUE, FALSE, NA, TRUE, FALSE,
                       FALSE, NA, TRUE, FALSE, FALSE)
)

at_risk <- krs[!krs$baseline_partner, ]

cat("全参加者      :", nrow(krs), "\n")                                   # 10
cat("リスク集団    :", nrow(at_risk), "\n")                               #  8
cat("恋に落ちた    :", sum(at_risk$fell_in_love), "\n")                   #  3
cat("正しいリスク  :", sum(at_risk$fell_in_love) / nrow(at_risk), "\n")   # 0.375
cat("間違えた分母  :", sum(krs$fell_in_love, na.rm = TRUE) / nrow(krs), "\n")  # 0.3

    結果はこうなります。

    数え方 分子 分母 値
    正しい（リスク集団） 3 8 37.5 %
    間違い（参加者全員） 3 10 30.0 %

    同じ3件の恋が、分母のとり方だけで 37.5 % にも 30.0 % にもなります。 差は 7.5 ポイント。10人でこれです。

    コードからの小さな教訓

    at_risk に絞ると、欠測（NA / pd.NA）がひとりもいなくなります。 偶然ではありません。欠測していたのは 「そもそも発生しようがないので観察していない人」だったからです。 リスク集団を正しく定義すると、分子の欠測はしばしば自然に消えます。 逆に言えば、na.rm = TRUE を機械的に付けたくなったときは、 分母を間違えているサインかもしれません。

    ロマンス先生の赤ペン ― よくある誤り¶

    誤り1　分母を「知り合い全員」にする

    「友達5人中3人」の5人は、恋の話をしてくれた友達です。 恋がうまくいった人ほど報告したくなるなら、分子だけが選ばれて膨らみます。 これは第7章で扱う選択バイアスの原型です。 分母は「結果を知る前に決められる」ものでなければなりません。

    誤り2　期間を言わない

    「恋人ができる確率は60％」 ― いつまでに？ 1か月なら大変な流行、10年ならごく普通です。 期間を決めるまで、それが何の確率なのかが決まりません。 次回 4-2 の主題になります。

    誤り3　状態を発生と言い換える

    「片恋野高校は片思いしてる生徒だらけだ」＝ 有病の話。 「片恋野高校は恋が生まれやすい」＝ 発生の話。 後者は前者から出てきません。4-5 で数字ごと分解します。

    この回に出てきた用語¶

    用語 English この回での意味
    事象・発生・罹患 event / incidence 恋に落ちる
    有病（状態） prevalence 恋の病にかかっている（片思い期・恋愛期）
    潜伏期 incubation period 好きになりはじめてから自覚するまで
    発症日 date of onset 「これは恋だ」と自覚した日
    リスク集団・感受性者 population at risk / susceptible まだ発症していない人
    病期 stage 片思い期と恋愛期。どちらも有病
    寛解 remission 振られる・諦める・別れる。成就は含まない
    免疫がある人（分母の外） immune いま恋愛に関心がない人
    閉鎖集団 closed population 2026年4月入学の参加者200人
    開放集団（動的集団） open / dynamic population 軽音サークルの部員
    リスク集団への参入・離脱 entry / exit 学籍に入った日と抜けた日

    （第4章ぶんの一覧は 用語集）

    練習問題¶

    問1　次のうち、発生（事象）の話はどれか。すべて選べ。

    1. 恋都大学の学生の12％が、現在片思い中である
    2. 経済学部では、昨年 34組の交際が始まった
    3. 恋都大学の学生は、平均して年に1.2回失恋する
    4. 大学院生の8％が交際中である
    解答

    2 と 3。 どちらも「〜が起きた回数」を数えています。 1 と 4 は「いま何割がその状態か」＝有病の話です。 3 は同じ人に何度も起こりうる繰り返す事象で、 リスクではなく率で扱うほうが自然です（→ 4-3, 4-6）。

    問2　恋都スタディに参加した新入生200人を1年追跡したい。 追跡開始時点で 40人がすでに交際中、15人が「いまは恋愛に関心がない」と答えた。 このとき、リスクの分母は何人か。

    解答

    145人（200 − 40 − 15）。

    交際中の40人はすでに発症済み、15人は感受性がない（免疫がある扱い）ため、 どちらも「これから恋に落ちうる人」ではありません。

    なお、この15人を分母から外したことは、そう定義したと書いておくべき判断です。 「関心がない」は自己申告で、1年のあいだに変わりうるからです。 定義が変われば分母が変わり、分母が変われば数字が変わる ― それを隠さず書くのが疫学の作法です。

    問3　雪野が言った。 「片恋野高校は、生徒の16.7％が片思い中でした。うちの学生は9.1％。 やっぱり片恋野のほうが恋が生まれやすいんですね！」

    ロマンス先生は何と答えるか。40字以内で。

    解答例

    「それは有病の数字です。片思いが長引いているだけかもしれません」

    片思い中の人の割合は、新しく恋に落ちる勢いと 片思いが続く長さの両方で決まります。 片恋野高校は「恋が生まれやすい」のではなく「恋が終わらない」のかもしれない。 この二つを数式で切り分けるのが 4-5 です。

    次回予告 ― 4-2 リスク ― 期間は、リスクの一部

    分母は決まった。次は時間です。 「恋都大学の新入生が恋に落ちるリスクは29％」― この一文には、まだ決定的に足りないものがあります。
