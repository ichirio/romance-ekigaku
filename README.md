# ロマンスの疫学 ― 科学的思考への誘い

恋の病を題材にした疫学の入門記事。

架空の私鉄・恋ヶ丘電鉄の沿線で、ロマンス先生と学生たちが、
恋がいつ・誰に・どれだけ起きているのかを数えていく。
題材は柔らかいが、使う道具は本物のまま ―
リスク、発生率、有病割合、リスク比、発生率比、リスク差、NNT。

**サイト: https://ichirio.github.io/romance-ekigaku/**

## 収録

第4章「恋の病の発生と因果的効果の測定」全8話。
記事中の数値はすべて Python と R で実行して確認したもの。数値・事例は架空。
