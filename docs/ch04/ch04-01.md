# 4-1　「恋に落ちた人」を数える前に

> 恋ヶ丘大学　― 事象と状態、リスク集団、閉鎖集団と開放集団

---

恋ヶ丘大学の学食。**雪野順**が、トレイを置くより先に言った。

> 「先生、やっぱりうちの大学って、恋が生まれやすいんですよ。
> だって私の友達、**5人中3人**に恋人ができたんです。60％ですよ、60％」

**ロマンス先生**は、味噌汁を持ち上げかけた手を止めて、こう言った。

> 「**その分母、なんですか？**」

---

## 雪野の勘違い

雪野の「60％」には、疫学が要求する三つのことが、どれ一つ書かれていません。

1. **何を数えたのか**（「恋人ができた」とは、いつ・どの状態になったことか）
2. **誰の中で数えたのか**（その5人は、どういう理由で選ばれた5人か）
3. **いつからいつまで数えたのか**（1か月の話か、大学4年間の話か）

疫学の指標は、例外なく次の形をしています。

$$
\text{指標} = \frac{\text{何を数えたか}}{\text{誰の中で、どれだけの時間について数えたか}}
$$

**分子より、分母のほうがずっと難しい。** この章はそのための章です。

---

## 1. 何を数えるか ― 事象と状態を分ける

恋の病について言えることは、大きく二種類あります。

| 言い方 | 種類 | 疫学では |
|---|---|---|
| 「恋に落ちた」 | **事象**（event）＝ 一瞬の出来事 | 発生・罹患 incidence |
| 「恋煩いの最中である」 | **状態**（state）＝ 続いているもの | 有病 prevalence |
| 「失恋した」 | 事象 | 状態からの離脱（治癒） |

!!! danger "第4章で一番潰したい誤り"
    **「恋煩い中の人が多い」と「恋に落ちる人が多い」は、まったく別の話です。**
    前者は有病、後者は発生。
    片思いが長引く街では、新しい恋がほとんど生まれていなくても、
    恋煩い中の人の割合はいくらでも高くなります（→ [4-5](../roadmap.md)）。

### 発生を数えるには「いつ発生したか」を決めねばならない

恋の病には**潜伏期（incubation period）**があります。
出会った日と、「これは恋だ」と自覚した日は違う。ときには何か月も違う。

結核でも同じ問題が起きます。感染した日と発症した日は違い、
**疫学は普通、観察できるほう（発症）を発生日として使います。**

恋ヶ丘スタディも、そこに倣ってこう決めています。

> **恋の病の発生日 ＝ 本人が「これは恋だ」と自覚した日**（自己申告）

出会った日ではありません。観察できないからです。

雪野が不満そうに言う。

> 「自己申告なんて、当てになりますか？」

> 「なりません」とロマンス先生。「だから**そう定義したと明記する**んです。
> 当てになる定義があるのではなく、**書いてある定義**があるだけです。
> 当てにならなさは第7章（誤分類）で正面から扱います。今は、
> **定義を書かずに数え始めないこと**だけ覚えてください」

---

## 2. 誰の中で数えるか ― リスク集団

分子に入りうる人だけが、分母に入れます。これが**リスク集団（population at risk）**です。
感染症の言葉では**感受性者（susceptible）**。

恋の病でいえば、**恋に落ちうる人**です。

| 追跡開始時点の状態 | リスク集団に入るか | 理由 |
|---|---|---|
| 誰にも恋していない | **入る** | これから恋に落ちうる |
| すでに片思い中 | **入らない** | もう発症済み（有病者） |
| すでに交際中 | **入らない** | 発症済み・恋愛市場の外 |
| いまは恋愛に関心がない | **入らない** | 感染症でいう「免疫がある」状態 |

麻疹の発生率を計算するとき、すでに免疫を持つ人を分母に入れたら、率は不当に小さくなります。
恋の病でもまったく同じで、**「恋に落ちようがない人」を分母に入れると、恋は起きにくく見えます。**

### 一度失恋した人は、リスク集団に戻る

恋の病は、麻疹より**風邪に近い**病気です。何度でも罹ります。

```
恋に落ちる ──▶ 恋煩い中 ──▶ 失恋／成就 ──▶ また恋に落ちうる
   (発生)        (有病)         (治癒)          (再び感受性者)
```

つまりリスク集団のメンバーは、**追跡の途中で出たり入ったりします。**
これを厳密に扱う道具が、次々回に出てくる**人時（person-time）**です。

---

## 3. いつからいつまで ― 閉鎖集団と開放集団

雪野の「5人」は、いつからいつまでの5人でしょうか。
ここで集団は二種類に分かれます。

=== "閉鎖集団（closed population）"

    **一度決めたら、あとから誰も入ってこない集団。**

    例：**2026年4月に恋ヶ丘大学に入学した新入生 200人**。
    2026年5月に転入してきた学生は、この集団には入りません。
    集団は減ることはあっても（転出・追跡不能）、増えません。

    → 全員を同じ期間追えるので、**リスク（累積発生割合）**が計算できます。

=== "開放集団（open / dynamic population）"

    **出入りが自由な集団。**

    例：**軽音サークルの部員**。
    毎年新入生が入り、毎年誰かが卒業し、途中で辞める人もいます。
    「部員は何人」と言っても、それは今日の写真にすぎません。

    → 一人ひとりの**在籍時間が違う**ので、リスクではなく
    **発生率（incidence rate）**を使います。

!!! note "この章の見通し"
    - 閉鎖集団 → **リスク** → [4-2](../roadmap.md)
    - 開放集団 → **発生率（人時）** → [4-3](../roadmap.md)
    - 両者の関係 → [4-4](../roadmap.md)

小堀定時が、手帳を開いて静かに補足する。

> 「学籍には**入った日と、抜けた日**が必ず記録されています。
> 疫学が一人ひとりについて知りたいのは、結局それだけです。
> **いつリスク集団に入って、いつ出たか。**」

---

## 手を動かす

恋ヶ丘スタディの縮小版（10人）で、分母を間違えるとどうなるかを見ます。

- `baseline_partner` … 追跡開始時点ですでに交際中か
- `fell_in_love` … 追跡1年のあいだに恋に落ちたか（交際中の人は対象外なので欠測）

=== "Python"

    ```python
    import pandas as pd

    krs = pd.DataFrame({
        "id": range(1, 11),
        "station": ["恋ヶ丘"] * 5 + ["片思ヶ丘"] * 5,
        "baseline_partner": [False, False, True, False, False,
                             False, True, False, False, False],
        "fell_in_love": pd.array([True, False, None, True, False,
                                  False, None, True, False, False],
                                 dtype="boolean"),
    })

    # 分母は「追跡開始時点で恋に落ちうる人」＝ リスク集団だけ
    at_risk = krs[~krs["baseline_partner"]]

    print("全参加者      :", len(krs))                                    # 10
    print("リスク集団    :", len(at_risk))                                #  8
    print("恋に落ちた    :", at_risk["fell_in_love"].sum())               #  3
    print("正しいリスク  :", at_risk["fell_in_love"].sum() / len(at_risk))   # 0.375
    print("間違えた分母  :", krs["fell_in_love"].sum() / len(krs))           # 0.3
    ```

=== "R"

    ```r
    krs <- data.frame(
      id      = 1:10,
      station = rep(c("恋ヶ丘", "片思ヶ丘"), each = 5),
      baseline_partner = c(FALSE, FALSE, TRUE, FALSE, FALSE,
                           FALSE, TRUE,  FALSE, FALSE, FALSE),
      fell_in_love     = c(TRUE, FALSE, NA, TRUE, FALSE,
                           FALSE, NA, TRUE, FALSE, FALSE)
    )

    at_risk <- krs[!krs$baseline_partner, ]

    cat("全参加者      :", nrow(krs), "\n")                                   # 10
    cat("リスク集団    :", nrow(at_risk), "\n")                               #  8
    cat("恋に落ちた    :", sum(at_risk$fell_in_love), "\n")                   #  3
    cat("正しいリスク  :", sum(at_risk$fell_in_love) / nrow(at_risk), "\n")   # 0.375
    cat("間違えた分母  :", sum(krs$fell_in_love, na.rm = TRUE) / nrow(krs), "\n")  # 0.3
    ```

結果はこうなります。

| 数え方 | 分子 | 分母 | 値 |
|---|---|---|---|
| **正しい**（リスク集団） | 3 | 8 | **37.5 %** |
| 間違い（参加者全員） | 3 | 10 | 30.0 % |

同じ3件の恋が、分母のとり方だけで **37.5 % にも 30.0 % にもなります。**
差は 7.5 ポイント。10人でこれです。

!!! tip "コードからの小さな教訓"
    `at_risk` に絞ると、**欠測（`NA` / `pd.NA`）がひとりもいなくなります。**
    偶然ではありません。欠測していたのは
    「そもそも発生しようがないので観察していない人」だったからです。
    **リスク集団を正しく定義すると、分子の欠測はしばしば自然に消えます。**
    逆に言えば、`na.rm = TRUE` を機械的に付けたくなったときは、
    **分母を間違えているサインかもしれません。**

## ロマンス先生の赤ペン ― よくある誤り

!!! failure "誤り1　分母を「知り合い全員」にする"
    「友達5人中3人」の5人は、**恋の話をしてくれた友達**です。
    恋がうまくいった人ほど報告したくなるなら、分子だけが選ばれて膨らみます。
    これは第7章で扱う**選択バイアス**の原型です。
    分母は「結果を知る前に決められる」ものでなければなりません。

!!! failure "誤り2　期間を言わない"
    「恋人ができる確率は60％」 ― **いつまでに？**
    1か月なら大変な流行、10年ならごく普通です。
    **期間を決めるまで、それが何の確率なのかが決まりません。**
    次回 4-2 の主題になります。

!!! failure "誤り3　状態を発生と言い換える"
    「片思ヶ丘は片思いしてる人だらけだ」＝ **有病**の話。
    「片思ヶ丘は恋が生まれやすい」＝ **発生**の話。
    後者は前者から出てきません。4-5 で数字ごと分解します。

## この回に出てきた用語

| 用語 | English | この回での意味 |
|---|---|---|
| 事象・発生・罹患 | event / incidence | 恋に落ちる |
| 有病（状態） | prevalence | 恋煩いの最中である |
| 潜伏期 | incubation period | 出会いから自覚まで |
| 発症日 | date of onset | 「これは恋だ」と自覚した日 |
| リスク集団・感受性者 | population at risk / susceptible | 恋に落ちうる人 |
| 免疫がある人（分母の外） | immune | いま恋愛に関心がない人 |
| 閉鎖集団 | closed population | 2026年4月入学の新入生200人 |
| 開放集団（動的集団） | open / dynamic population | 軽音サークルの部員 |
| リスク集団への参入・離脱 | entry / exit | 学籍に入った日と抜けた日 |

（第4章ぶんの一覧は **[用語集](../glossary.md)**）

## 練習問題

**問1**　次のうち、**発生**（事象）の話はどれか。すべて選べ。

1. 恋ヶ丘大学の学生の12％が、現在片思い中である
2. 経済学部では、昨年 34組の交際が始まった
3. 恋ヶ丘大学の学生は、平均して年に1.2回失恋する
4. 大学院生の8％が交際中である

??? success "解答"
    **2 と 3。** どちらも「〜が起きた回数」を数えています。
    1 と 4 は「いま何割がその状態か」＝**有病**の話です。
    3 は同じ人に何度も起こりうる**繰り返す事象**で、
    リスクではなく率で扱うほうが自然です（→ 4-3, 4-6）。

---

**問2**　恋ヶ丘大学の新入生200人を1年追跡したい。
追跡開始時点で 40人がすでに交際中、15人が「いまは恋愛に関心がない」と答えた。
このとき、**リスクの分母**は何人か。

??? success "解答"
    **145人**（200 − 40 − 15）。

    交際中の40人はすでに発症済み、15人は感受性がない（免疫がある扱い）ため、
    どちらも「これから恋に落ちうる人」ではありません。

    なお、この15人を分母から外したことは、**そう定義したと書いておくべき判断**です。
    「関心がない」は自己申告で、1年のあいだに変わりうるからです。
    定義が変われば分母が変わり、分母が変われば数字が変わる ―
    それを隠さず書くのが疫学の作法です。

---

**問3**　雪野が言った。
「片思ヶ丘の住民は、16.7％が片思い中でした。恋ヶ丘大学は9.1％。
やっぱり片思ヶ丘のほうが恋が生まれやすいんですね！」

ロマンス先生は何と答えるか。40字以内で。

??? success "解答例"
    「それは**有病**の数字です。片思いが**長引いている**だけかもしれません」

    片思い中の人の割合は、**新しく恋に落ちる勢い**と
    **片思いが続く長さ**の両方で決まります。
    片思ヶ丘は「恋が生まれる街」ではなく「**恋が終わらない街**」なのかもしれない。
    この二つを数式で切り分けるのが 4-5 です。

---

!!! quote "次回予告 ― 4-2 リスク ― 期間は、リスクの一部"
    分母は決まった。次は**時間**です。
    「恋ヶ丘大学の新入生が恋に落ちるリスクは29％」―
    この一文には、まだ決定的に足りないものがあります。
