# 第4章　恋の病の発生と因果的効果の測定

疫学の指標はすべて、**「何を・誰の中で・どれだけの時間について数えたか」**の
組み合わせでできています。この章は、その組み合わせ方をひとつずつ組み立てていく八回です。

---

## この章で扱う指標

| 指標 | 記号 | 値の範囲 | 単位 | 何の写真か |
|---|---|---|---|---|
| リスク（累積発生割合） | \(R\) | 0 〜 1 | なし（**期間が必須**） | 期間中に何割が発生したか |
| 発生率 | \(IR\) | 0 〜 ∞ | 1/時間 | 単位時間あたりの発生の勢い |
| 有病割合 | \(P\) | 0 〜 1 | なし | ある**時点**で何割がその状態か |
| リスク比 | \(RR\) | 0 〜 ∞ | なし | 比較（乗法） |
| 発生率比 | \(IRR\) | 0 〜 ∞ | なし | 比較（乗法） |
| リスク差 | \(RD\) | −1 〜 1 | なし | 比較（加法） |
| 治療必要数 | \(NNT\) | ― | 人 | 効果を人数に翻訳したもの |
