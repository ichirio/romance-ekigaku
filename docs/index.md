# ロマンスの疫学 ― 科学的思考への誘い

> 結核でもコレラでもなく、**恋の病**を数える。

---

これは、**ロスマンの『疫学 ― 科学的思考への誘い』**をもじった疫学の入門記事です。
もじってあるのは、たった一箇所。

- **ロスマン** → **ロマンス**（ロ・ス・マ・ン のアナグラム）

**「疫学」はもじっていません。** リスク、発生率、有病割合、リスク比、発生率比 ―
出てくる指標の定義も注意点も、本物の教科書のまま、一切薄めていません。
変えたのは**題材だけ**です。教科書が結核やインフルエンザで説明するところを、
この本は**恋の病**で説明します。

!!! quote "ロマンス先生の第一声"
    「疫学は、病気を数えるための学問ではありません。
    **集団の中で起きる出来事を数えるための学問**です。
    出来事が結核である必要は、どこにもない。」

架空の私鉄・**恋ヶ丘電鉄**の沿線で、恋愛至上主義の**ロマンス先生**が、
恋の病の流行を追いかけます。曝露は駅前の占い館「**易の間**」。
知りたいのは、「**占ってもらうと、恋は実るのか**」。

---

## 「恋の病」は、疫学の道具にきれいに乗る

日本語にはもともと「恋煩い」「恋の病」という言い方があります。
これは比喩として便利なだけでなく、**疫学の語彙が一語も改造せずに乗る**という点で、
教材として極めて優秀です。

| 疫学の言葉 | 恋の病では |
|---|---|
| 感受性者（susceptible） | 恋に落ちうる人 |
| 曝露（exposure） | 占い館に通う、学園祭に行く |
| 罹患・発生（incidence） | 恋に落ちる |
| 潜伏期（incubation period） | 出会ってから自覚するまでの時間 |
| 有病（prevalence） | いま恋煩いの最中である |
| 罹病期間（duration） | 片思いが続いた長さ |
| 治癒（recovery） | 成就する、あるいは諦める |
| 再感染（reinfection） | また別の人に恋をする |
| 流行（epidemic） | 学園祭シーズンの恋の多発 |

!!! note "念のため"
    恋を病気に見立てるのは、恋が悪いものだという意味ではありません。
    疫学の道具が「集団の中で起きる出来事を数える道具」であることを見せるための、
    ただの見立てです。ロマンス先生は誰よりも恋を肯定しています。

---

## この本が潰したい誤解

!!! danger "「片思い中の人が多い街」は、「恋が生まれやすい街」ではない"
    これは**有病割合**と**発生率**の取り違えです。
    片思いが長引く街では、新しい恋がほとんど生まれていなくても、
    片思い中の人の割合はいくらでも高くなります。

    第4章の第5話で、この罠を数字で分解します。
