# ロマンスの疫学 ― 科学的思考への片思い

> 恋の病は、いつ、誰に、どれだけ起きているのか。

---

京の都の北のはずれに、恋都大学はある。

四月。白川の桜が散りはじめるころ、三千人近い新入生が正門をくぐる。
同じ日に、同じ場所に、同じ顔ぶれが揃う。
疫学者にとって、これほど数えやすい集団はない。

そのうちの二百人が、一年だけ、ある研究に付き合うことになる。

その大学に、**路須万兼寿（ろすまん かねす）**という疫学者がいる。
学生たちはこの名前を並べ替えて、いつのまにか**ロマンス先生**と呼ぶようになった。
恋の話になると早口になるが、数字の話になるともっと早口になる。
学生が数字を持ってくると、必ず最初にこう言う。

> 「**その分母、なんですか？**」

先生が数えているのは、**恋の病**である。

リスク、発生率、有病割合、リスク比、発生率比、リスク差、NNT ―
恋を数えるのに、疫学の道具はそのまま使える。

## 鴨川の向こうの高校の話

鴨川を渡った先に、高大連携先の**府立片恋野高校**がある。
調べてみると、生徒の 16.7 % が片思いの最中だった。大学生は 9.1 %。

学生の**雪野順**は、これを見て言った。
「片恋野高校のほうが、恋が生まれやすいんですね」

ロマンス先生は、しばらく黙ってからこう答えた。

> 「片恋野高校の恋の発生率は、**うちの学生の半分**です」

同じ二つの集団の数字が、見る指標を変えるだけで逆を向く。
片恋野高校は恋が生まれやすいのではなく、**恋が終わらない**のだった。

この取り違えを数式ごと分解するのが [4-5](ch04/ch04-05.md) で、
そこへ至るまでの道具立てを組むのが、第4章の残りの回である。
