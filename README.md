# ロマンスの疫学 ― 科学的思考への誘い

ロスマン『疫学 ― 科学的思考への誘い』をもじった疫学入門。
もじりは **ロスマン→ロマンス** の一箇所だけで、「疫学」はそのまま。
結核やコレラの代わりに、**恋の病**を題材にリスク・発生率・有病割合を学ぶ。

- サイト: https://ichirio.github.io/romance-ekigaku/
- 中心は **第4章**（恋の発生と因果的効果の測定）: リスク / 発生率 / 有病割合 / RR / IRR / RD / NNT

## 方針

パロディにするのは**タイトルと舞台と語り口だけ**。
疫学の定義・指標・注意点はロスマン準拠で一切いじらない。
各記事の末尾に用語対照表を置き、読者がいつでも本物の教科書に戻れるようにする。

詳細は [docs/setting.md](docs/setting.md) を参照。
