# 全体ロードマップ

恋ヶ丘スタディの記録は、**第4章から始まります。**
何をどう数えるかが決まらないうちは、原因の話にも、不確かさの話にも進めないからです。

数え方が決まったら、次はそのデータをどう手に入れるか。それが第5章です。

    2. 「片思いの多い街」が**必ずしも「恋の生まれやすい街」ではない**理由を説明できる
    3. 比と差の**どちらを使うかは目的で決まる**と言える（片方が正しいのではない）

| 話 | タイトル | 扱う疫学の中身 |
|---|---|---|

| 5-2 | [コホート研究 ― 曝露から出発して、待つ](ch05/ch05-02.md) | 閉鎖／開放コホート、前向きと後ろ向き、代償 |
| 5-3 | [症例対照研究① ― なぜ全員を追わなくてよいのか](ch05/ch05-03.md) | 起源集団、対照の役割、効率 |

!!! note "第5章のゴール"
    1. コホート研究と症例対照研究の**関係**を説明できる（後者は前者の劣化版ではない）
    2. 対照の適格性を **would-be case の基準**で判定できる
    3. **対照の抜き方によって、オッズ比が何を推定するかが変わる**と言える
