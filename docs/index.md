# ロマンスの疫学 ― 科学的思考への片思い

> 恋の病は、いつ、誰に、どれだけ起きているのか。

---

京の都の北のはずれに、恋都大学はある。

四月。白川の桜が散りはじめるころ、三千人近い新入生が正門をくぐる。
同じ日に、同じ場所に、同じ顔ぶれが揃う。
疫学者にとって、これほど数えやすい集団はない。

医学部棟の三階に、**路須万兼寿（ろすまん かねす）**という疫学者がいる。
学生たちはこの名前を並べ替えて、いつのまにか**ロマンス先生**と呼ぶようになった。
恋の話になると早口になるが、数字の話になるともっと早口になる。
学生が数字を持ってくると、必ず最初にこう言う。

> 「**その分母、なんですか？**」

先生が数えているのは、**恋の病**である。

リスク、発生率、有病割合、リスク比、発生率比、リスク差、NNT ―
恋を数えるのに、疫学の道具はそのまま使える。

話は、[ある四月の学食](ch04/ch04-01.md)から始まる。
